## 答案写法·条号策略校准（2026-08-13 用户质询后生效）
- **背景**：教练此前把"每问必须写条号"设为训练硬性要求；用户质询：之前查的众合讲师意见不是说不必写吗？
- **众合讲师口径（2026-08-11 网络检索）**：刑法柏浪涛=不写法条；民法孟献贵=可选·锦上添花；行政法李佳=两手准备；刑诉左宁=点到为止·分析为主；民诉戴鹏=金句为主·用得不多；理论法=不需要法条。
- **校准结论（已生效）**：
  1. 条号要求降级为**分科弹性**——行政法/刑诉/民法（规则性强的点）：写得出就写、写不准写"依据《××法》关于××的规定"；刑法/民诉/理论法：不强制写条号。**（2026-08-22 用户补充：观点展示题型无论何科，一律不写条号、不表明自己观点）**。
  2. 铁律两条：①**写就写对，写错条号代价>不写（宁缺毋错）**；②底线=每条理由至少锚定"制度/法条名"（防规则悬空、张冠李戴），但不需要背数字。
  3. 训练期仍保留"规则锚定"训练（结论挂到正确制度/法条名），目的是防"凭感觉写规则"（用户失分多是规则说偏，非没背条号）；开卷定位速度训练（冲刺计划原则2）不变。
  4. 批改侧：条号缺失不再一律计失分；只对"条号写错"严格扣分；"未锚定制度/法条名"仍计轻失分（#法条缺位 已从硬伤降级）。
  5. 2026-08-12 民诉题14 批改中"延续硬伤·条号仍不写"条目按本校准作废重评。
