## 出题+批改严谨性纪律
- 出题侧：事实无歧义(善意/恶意/知情须明写，禁暗示词)；程序立场明确可辩护；交付前自查唯一解/一致性
- 批改侧：回读题干原文；负面清单绝对判断须模板+法条双重核对；机构答案仅校验基准；自命题标「教练参考稿·非官方」；逐问附完整标准答案全文；量化得分/失分点+类型归类；严格0/1判分(无半分/定性反=0/笼统=0/并列缺一=0)

## 条号策略（8/13校准；8/22补充）
- 分科弹性：行政/刑诉/民法可写(写对才写)；刑法/民诉/理论法不强制
- 铁律：写就写对(宁缺毋错)；每理由至少锚定制度/法条名
- 观点展示题型：无论何科，一律不写条号、不表明自己观点
