## 一、民法实体法（理解错误的考点）

### 考点1 一物二卖中的物权变动与履行不能
- **我理解错在哪**：问1只写"甲已交付丙"，未点出"履行不能"；问3把丙（无合同、非物权人）与丁（侵害丙所有权）搅在一句，法律关系不分层。
- **正确答题要点**：
  - 甲将家具交付丙 → 丙基于**有权处分**（甲是所有权人）**继受取得**所有权，**非善意取得**；
  - 甲对乙陷**履行不能** → 乙不得请求继续履行，只能转**违约损害赔偿**；
  - 丙是所有权人，乙对丙无请求权（合同相对性 + 非物权人）；丁侵害的是丙的所有权 → 乙对丁亦无请求权；
  - 甲根本违约致乙合同目的不能实现 → 乙可**解除**（§563），解除后仍有损害赔偿（§566）。
- **关联原题**：诊断题 Q1【已改对】

### 考点2 善意取得四要件（10/10 年必考）
- **我理解错在哪**：问1把"善意取得"搅进合同效力问（负担行为 vs 处分行为不分）；问2首答漏"善意"要件，二轮写善意但漏"无权处分前提"与"合理价格"明确归入。
- **正确答题要点**：四要件逐项列 + 事实归入——①转让人**无权处分** ②受让人**善意**（不知且不应知）③**合理价格** ④动产**交付**/不动产**登记**（§311）；**合同效力（负担行为）与善意取得（处分结果）是两问**，问合同效力时不答善意取得。
- **关联原题**：善意取得 Q1/Q2【仍易错】

### 考点3 物权请求权（原物返还）的前提
- **我理解错在哪**：非物权人（乙）主张向丙/丁请求原物返还；善意取得 Q4 认为甲可对乙主张"物权返还权"。
- **正确答题要点**：原物返还请求权（§235）前提是请求人系**所有权人**且对方为**现占有人**；乙非所有权人 → 对丙丁无返还请求权；甲对乙：乙已不占有画、丙是所有权人，甲对乙无物权返还前提 → 走债权救济。
- **关联原题**：诊断 Q3、善意取得 Q4

### 考点4 对无权处分人的债权救济三路径
- **我理解错在哪**：认为甲可对乙（无权处分人）主张物权返还。
- **正确答题要点**：甲乙借用合同 + 乙无权处分 → 甲对乙三路径——**违约**（§577，借用合同）、**侵权**（§1165，侵害所有权）、**不当得利**（§985，乙获 75 万无法律根据）；违约与侵权**竞合择一**，不得并用。
- **关联原题**：善意取得 Q4

### 考点5 担保范围 vs 担保财产（概念区分）
- **我理解错在哪**：问1写"担保范围 = 丙以房屋价值作担保范围"，混淆担保财产与担保范围。
- **正确答题要点**：担保**财产** = 提供担保的特定财产（房屋/车/字画）；担保**范围** = 法定（§389）= 主债权 + 利息 + 违约金 + 损害赔偿金 + 保管担保财产费用 + 实现担保物权费用；未约定 → 适用法定范围。
- **关联原题**：担保 Q1

### 考点6 流担保条款与质权设立
- **我理解错在哪**：上版错写"如办理质押登记才可优先受偿"。
- **正确答题要点**：**质权自交付设立**（动产），看交付非登记（题目已交付 → 质权已设）；流担保条款（约定不还车归乙）无效（§428）但不影响质权设立；**抵押权才看登记**。
- **关联原题**：担保 Q1

### 考点7 混合担保清偿顺序
- **我理解错在哪**：问2只引 §392 不代入本案顺序结论。
- **正确答题要点**：有债务人自身物保 + 第三人担保 → **债务人自身物保优先**清偿（§392）；第三人担保人间无约定 → 无相互追偿权（新担保解释）。
- **关联原题**：担保 Q2

### 考点8 放弃债务人自身物保的后果
- **我理解错在哪**：问4写"丙的担保责任不变"。
- **正确答题要点**：债权人放弃**债务人自己**提供的物保 → 其他担保人（第三人）在放弃权利范围内**相应减轻/免除**责任（§409②、§435），**非不变、非全免**。
- **关联原题**：担保 Q4【仍易错】

### 考点9 保证方式定性（一般保证 vs 连带保证）
- **我理解错在哪**：把"若甲不能清偿，王某承担"判为连带保证。
- **正确答题要点**：**"不能清偿/不能履行才承担" = 一般保证**（先诉抗辩）；**"不履行 + 无条件承担" = 连带保证**；以题面措辞为准；即便一般保证，诉讼中**自认连带 → 诉讼上认诺 → 可判连带**。
- **关联原题**：2023 真题 Q7【仍易错】
- **补充（2026-08-08 教练更正）**：一般保证人**可以**作为共同被告与债务人同诉（《担保制度解释》第26条），先诉抗辩权不排斥其参加诉讼，而是体现于判决执行顺序（先执行债务人财产、不足部分由保证人承担）；原告诉请"共同清偿责任"表述错误——一般保证人负**补充责任、非连带**。此点教练原批"非共同被告"有误，已更正。

### 考点10 诉讼解除 + 撤诉效力
- **我理解错在哪**：Q5 推理矛盾（先写"副本送达后解除"，又写"撤诉后未解除"）。
- **正确答题要点**：诉讼解除须"**法院确认**"该主张，合同自副本送达时解除（§565）；**撤诉 → 法院未作出判决确认 → 条件不成就 → 合同尚未解除**；乙可再诉；踩分关键词"**法院并未作出判决确认**" + "**合同尚未解除**"。
- **关联原题**：2023 真题 Q5【仍易错】

### 考点11 夫妻共同债务分析框架
- **我理解错在哪**：Q8 只写"合同相对性、未签字不连带"，漏展示分析框架。
- **正确答题要点**：§1064 三要件审查——①**共债共签**（未签不满足）②**事后追认**（无不满足）③**共同生产经营**（任财务参与经营可能构成）；题干仅查明甲与王某混同、未查与李某混同且无签字/追认 → 证据不足 → 不连带；**须展示框架再落脚结论**。
- **关联原题**：2023 真题 Q8【仍易错】

## 二、民诉程序法（理解错误的考点）

### 考点12 商铺买卖≠不动产专属管辖（教练误判，现更正）
- **我理解错在哪（更正）**：此前写成"商铺买卖=不动产纠纷→专属管辖"，这是错的。正确：商铺买卖属于**一般合同纠纷**，**不适用**不动产专属管辖。原答"不属于专属管辖"其实正确。
- **正确答题要点**：依《民诉解释》§28，不动产专属管辖限于物权纠纷及四类合同（农村土地承包经营合同、房屋租赁合同、建设工程施工合同、政策性房屋买卖合同）。普通商铺/商品房买卖不在此列，按一般地域管辖（被告住所地/合同履行地）+ 协议管辖处理。
- **关联原题**：综合题 Q1【教练此前误判，现更正为一般合同纠纷管辖】

### 考点13 设备买卖 ≠ 不动产（即使已安装固定）
- **我理解错在哪**：2023 Q2 抗辩"设备已安装无法拆除 = 不动产"。
- **正确答题要点**：设备买卖争议核心是**价款支付**（合同义务）→ 非不动产物权变动 → 不适用不动产专属管辖（解释 §28）；已吸收 Q1 教训。
- **关联原题**：2023 真题 Q2【已改对】

### 考点14 无约定管辖 → 接收货币一方所在地
- **我理解错在哪**：漏"接收货币一方所在地 = 合同履行地"主路径；曾把牵连管辖当主路径。
- **正确答题要点**：合同纠纷 → 被告住所地**或**合同履行地（§24）；未约定 → 争议标的为**给付货币** → **接收货币一方所在地**为履行地（解释 §18）；**牵连管辖非标准答案主路径，别当踩分点**。
- **关联原题**：2023 真题 Q3

### 考点15 诉的单纯合并
- **我理解错在哪**：写"两合同**有事实牵连**…单纯合并不以牵连为要件"——逻辑矛盾。
- **正确答题要点**：单纯合并 = 两合同"**没有牵连**" → 可合并审理但**必须分别审理、分别判决**；有牵连的叫牵连合并；"**分别判决**"是独立采分点，别漏。
- **关联原题**：2023 真题 Q4

### 考点16 有独三绝不能当被告
- **我理解错在哪**：综合题 Q2 把林某（对商铺有共有权、反对原被告双方）错列为被告/共同被告。
- **正确答题要点**：林某对诉讼标的有**独立请求权** → **有独三** → 法院只能**依申请**准许参加，不得追加为被告；韩某为已登记所有权人，是有独三/无独三，**非被告**。
- **关联原题**：综合题 Q2【已改对】

### 考点17 适格被告 ≠ 实体责任
- **我理解错在哪**：Q2 评析里提前写李某"证据不足不连带"（把 Q5 的活提前干了）。
- **正确答题要点**：Q2 只答"**适格**"（乙主张 §1064 → 王/李是适格被告 → 答辩不成立）；Q4/Q5 才答"**实体责任**"（要不要赔）；**适格 ≠ 必败也 ≠ 必胜**，只回答"能不能当被告"；主张夫妻债务 → 法院"**应当**"列李某为共同被告。
- **关联原题**：综合题 Q2、2023 真题 Q2/Q6
