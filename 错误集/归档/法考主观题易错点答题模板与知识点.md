## 详细卡

### 易错点 1：物权请求权前提不清（非物权人主张原物返还）
- **易错表现**：① 甲对乙主张"物权返回权"（乙已不占有、丙是所有权人）；② 乙向丙、丁主张损害赔偿（乙非物权人）。
  对应错题：善意取得 Q4、诊断题 Q3。
- **考场答题模板**：
  1. **先定性主体身份**：谁享有物权（所有权/他物权）？谁是占有人？
  2. **再定请求权基础**：原物返还请求权（第235条）前提是"所有权人 vs 无权占有人"；非物权人不得主张，只能走债权救济。
  3. **句式**："甲系该画所有权人，丙基于善意取得取得所有权后，甲丧失所有权 → 甲对乙无物权返还前提（乙非占有人、甲非物权人），甲只能依借用合同向乙主张违约/侵权/不当得利。"
- **涉及知识点**：
  - 第235条 原物返还请求权（所有权人→无权占有人）
  - 善意取得第311条（受让人原始取得，原权利人丧失物权）
  - 债权救济三路径：违约第577条 / 侵权第1165条 / 不当得利第985条
  - 框架位置：民法框架·物权编 / 模板2（善意取得）

### 易错点 2：善意取得要件漏项
- **易错表现**：四要件（无权处分 / 善意 / 合理价格 / 交付）列不全，常漏"善意"或"合理价格"。
  对应错题：善意取得 Q2（首答漏善意，次答漏无权处分前提与合理价格）。
- **考场答题模板**：
  1. 遇"无权处分 + 第三人取得"案情，**强制四要件逐条列出 + 每条事实归入**。
  2. **句式**："依善意取得制度（第311条），须：①转让人无权处分（本案乙为借用人、非所有权人）；②受让人善意（丙不知情）；③以合理价格转让（75万≈市价80万）；④动产已交付（乙已交付画）。四要件齐备，丙取得所有权。"
  3. 检查点：写完数一遍——四个要件是否都在？每条是否跟了本案事实？
- **涉及知识点**：
  - 第311条 善意取得（四要件）
  - 第143条 民事法律行为效力（负担行为有效）
  - 第597条 无权处分合同效力（合同有效，物权变动效力待定）
  - 框架位置：民法框架·物权变动 / 模板2

### 易错点 3：混合担保顺序及放弃债务人自身物保的后果
- **易错表现**：① 不先就债务人自身物保实现；② 放弃债务人自身物保后称"第三担保人责任不变"。
  对应错题：担保综合 Q2、Q4。
- **考场答题模板**：
  1. **先分"谁提供物保"**：债务人自己 vs 第三人。
  2. **顺序**：有债务人自身物保的，债权人应先就该物保实现（第392条）；不足部分再就第三人物保/人保任选。
  3. **放弃后果**：债权人放弃**债务人自己**提供的物保 → 其他担保人（第三人）在放弃权利的范围内**相应减轻或免除**担保责任（第409条第2款 / 第435条）；非不变、非全免。
  4. **句式**："甲（债务人）自提供字画质权，乙应先就字画实现债权；丙、丁、戊为第三人担保，乙可任选。若乙放弃甲字画优先受偿，则丙、丁、戊在乙放弃的优先受偿权价值范围内相应免除担保责任。"
- **涉及知识点**：
  - 第392条 混合担保清偿顺序（债务人自身物保优先）
  - 第409条第2款 / 第435条 放弃担保物权的后果
  - 第700条 保证人追偿（向债务人）
  - 担保制度解释第13条 担保人之间未约定相互追偿则无权分担
  - 框架位置：民法框架·担保编 / 模板1（担保综合）

### 易错点 4：概念混淆（担保范围/担保财产、质权交付/抵押登记、负担/处分行为）
- **易错表现**：① "担保范围"写成"房屋价值"（实为担保财产）；② 质权说"办理登记才优先受偿"（质权看交付）；③ 合同效力与物权变动搅一起。
  对应错题：担保综合 Q1、善意取得 Q1。
- **考场答题模板**（考前背清三组区分）：
  1. **担保范围 vs 担保财产**：范围是"担保哪些债权"（法定：主债权+利息+违约金+损害赔偿金+保管担保财产+实现担保物权费用，第389条）；财产是"拿什么担保"（房屋/车/字画）。
  2. **质权交付 vs 抵押权登记**：动产质权自**交付**设立（第429条）；抵押权自**登记**设立（第402条，不动产/车辆等）。
  3. **负担行为 vs 处分行为**：合同有效（负担）≠ 物权变动（处分）；无权处分合同仍有效（第597条），物权变动效力待定。
  4. 动笔时**先点明概念**，再代入。
- **涉及知识点**：
  - 第389条 担保范围
  - 第402条 抵押权登记设立 / 第429条 质权交付设立
  - 第597条 无权处分合同效力
  - 框架位置：民法框架·担保编 / 物权变动

### 易错点 5：只引规则不代入案情（理由链断裂）
- **易错表现**：写完"依第392条……"就停，不给本案具体结论（如"先甲字画、再任选丙丁戊"）。
  对应错题：担保综合 Q2、善意取得 Q1。
- **考场答题模板**：
  1. 结构铁律：**结论先行 → 制度/法条 → 要件 → 事实归入 → 本案结论**。
  2. 每引一条规则，必落一个本案判断：**"→ 故本案中，___"**。
  3. 自检：阅卷人看"关键词 + 逻辑链"，只引法条无归入 = 没分。
- **涉及知识点**：
  - 众合主观题答题铁律（踩点给分、大小前提合写）
  - 纯法条题须写全要件情形，案情融合题写全要件+事实归入（条号可省）
  - 框架位置：答题模板库·通用踩分铁律

### 易错点 6：考点混淆 / 不分层（不同问、不同主体法律关系搅一起）
- **易错表现**：① 问1的善意取得写进问2；② 丙、丁法律关系不同却写一段。
  对应错题：善意取得 Q1、诊断题 Q3。
- **考场答题模板**：
  1. **每问只答本问考点**，不把上一问的结论当本问理由。
  2. **多主体各起一段**：丙、丁分别分析，每段独立"结论→依据→要件→归入"。
  3. 动笔前先列："本案有几个法律关系 / 几个主体？"逐个击破。
- **涉及知识点**：
  - 请求权基础思维（逐一检索、排除可能的请求权基础）
  - 第465条 合同相对性
  - 物权请求权主体限定（非物权人无物权请求权）
  - 框架位置：答题模板库·通用铁律（分层说理）

### 易错点 7：错别字与术语不严谨
- **易错表现**：① 戊（当事人）写成 戍（shù，防守）；② 把抵押人/出质人叫"保证人"。
  对应错题：担保综合全卷。
- **考场答题模板**：
  1. **保证人 = 人保**（保证合同）；**抵押人/出质人 = 物保**（担保物权）。勿混称"其他保证人"指物保人。
  2. 写完扫一遍专有名词：戊/己/庚/辛 等天干；保证/抵押/质押 概念。
- **涉及知识点**：
  - 第681条以下 保证（人保）
  - 第394条以下 抵押 / 第425条以下 质押（物保）
  - 框架位置：民法框架·担保编概念
