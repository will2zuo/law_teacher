# 法考主观题 · 备考记忆仓库（跨 PC 同步版）

本仓库 = 全部备考记忆的**自包含集合**。任意机器只要拿到这个文件夹（clone 或云盘同步），用 WorkBuddy 打开根目录 `law/` 作为项目，即获得完整记忆：纪律、错漏总账、考点清单、每日带读、避坑清单、每日日志、项目级记忆（`.workbuddy/memory/`）。

> 不依赖用户名、不依赖系统（Mac / Windows 均可）。所有文档互引用均为相对路径。

## 跨 PC 使用

### 方式一：git 私有仓（推荐，可回滚）
```bash
# 本机（已初始化，首次推送）
git remote add origin <你的私有仓地址，如 git@github.com:you/law-coach.git>
git push -u origin main        # 或 master，视默认分支名

# 另一台机器（Windows / 不同用户名均可）
git clone <私有仓地址> law
# 用 WorkBuddy 打开 clone 下来的 law/ 文件夹作为项目即可
```

### 方式二：云盘同步整个文件夹
把 `law/` 整个文件夹放进 百度网盘 / 微云 / OneDrive / iCloud Drive，另一台机器登录同云盘下载到任意路径，用 WorkBuddy 打开即可。

## Windows 特别注意
- 放哪都行：`D:\law`、`文档\law`、`C:\Users\<你的用户名>\WorkBuddy\law` 均可，用户名不同不影响。
- 换行符：本仓库 `.gitattributes` 已设 `eol=lf`，git 拉取不会产生 CRLF 噪音。
- 中文文件名 Windows（NTFS）完全支持。
- 专家（LawStudentCoach）为账号级，登录同 WorkBuddy 账号即自动可用；若以本地文件形式存在 `law/` 内，则随仓库同步。

## 验证纪律是否自动加载（换机后做一遍）
打开项目后问本会话：「今天还有什么纪律 / 我有哪些常驻规则」。
能背出 ⑪ 根因标签 / ⑫ 双轨 / ⑬ 带读 / ⑭ 执行模式，即加载成功。
若背不出：把 `law/.workbuddy/memory/*` 复制进 Windows 上新 workspace 的 `.workbuddy/memory/` 即可（旧句柄目录 `2026-08-19-14-24-43` 无关紧要，可忽略）。

## 维护约定
- 新增/修订纪律、错漏、考点，都直接改本仓库内对应文件并提交。
- 每日日志写在 `.workbuddy/memory/2026-08-XX.md`。
- 同步习惯：每天结束 `git add -A && git commit -m "..." && git push`（方式一）；云盘方式保持文件夹自动同步即可。
