# 法考主观题·行政法备考记忆分层表

> **核心校准**：法考主观题考场**禁止自带任何资料**（速查卡 / 笔记 / 手机均不可）。所谓"开卷" = 考场电脑内置**电子法律法规汇编系统**，可现查条号。
> 因此：**条号考场上查得出来，不必背**；真正要"装进脑子带进考场"的是**分析能力**（法规库只给字面法条，不给你怎么分析、怎么组织答案）。
> 本表把行政法备考内容明确分成两栏，刷题前看一眼，劲往哪使一目了然。

---

## 两栏总览

| 考场可查（检索地图，练方向不背数字） | 必须内化（框架 + 判断力 + 术语） |
|---|---|
| 各法条**条号**与具体文字 | 五步法答题结构 |
| 去哪部法、用什么关键词查（检索方向） | 六类题型识别（A–F） |
| 关联实体法条文（真题穿插） | 定性判断分水岭 |
| 裁量基准 / 程序细则的具体表述 | 法言法语术语 |
| | 易错点（避坑清单 · 条件反射） |

---

## 栏一：考场可查（平时用速查卡练"检索地图"，考场上靠脑内方向 + 电子法规库现查）

**你只需内化"检索方向"，条号数字本身不背。** 以下每个都是"知道去哪查 + 用什么词"即可：

- **《行政诉讼法》**（管"诉"）：撤销 §70 / 确认违法 §74 / 驳回 §69 / 履行 §72 / 变更 §77 / 被告 §26 / 受案 §12–13 → 关键词："撤销 主要证据不足""确认违法 无撤销内容""复议维持 共同被告"
- **《行政强制法》**（管"强制"）：定义 §2 / 实施程序 §18 / 查封清单 §24 → 关键词："两名以上 执法人员""查封清单 当场交付""暂时性控制"
- **《行政处罚法》**（管"处罚与执行"）：告知申辩 §44–45 / 不得加重 §62 / 逾期执行 §72 / 裁量基准 §34 → 关键词："加处罚款 百分之三""申请人民法院强制执行""裁量基准 公布"
- **《行政复议法》**（管"复议"）：管辖 §24 / 听取意见 §49 / 听证 §50 → 关键词："工作部门 本级政府""听取意见 记录在案""重大疑难 听证"
- **《行诉解释》**：增加诉讼请求截止 §70 → 关键词："起诉状副本送达被告后"
- **《国家赔偿法》**：直接损失 §36 / 违法归责 §2–4 → 关键词："直接损失 间接损失"
- **关联实体法**（真题穿插，如万兴案）：《安全生产法》§65 / §97 / §112 → 按行为性质检索

> **训练法**：刷题时先自己想"去哪部法、用什么词"，再翻速查卡核对，最后上真实法规库验证，逐步把方向焊进脑子，卡片即可退休。

## 栏二：必须内化（法规库给不了，必须自己会写）

### （1）框架
- **五步法**：结论先行 → 法条锚定 → 要件展开 → 归入本案 → 闭合（落判决 / 排除干扰）
- 每个定性 / 违法点必接后果，不停在"违法"二字

### （2）六类题型识别（见模板 20）
A 行为性质定性 / B 程序时间点 / C 被告管辖 / D 行政执行 / E 复议程序 / F 抽象规则 —— 看到题先判型，套对应微模板

### （3）定性判断分水岭（真正要记牢的"判断力"）
- 复议**维持** → 原机关 + 复议机关**共同被告**（改变则复议机关单独被告）
- **强制措施 vs 行政处罚**：暂时性控制 / 紧急预防 vs 最终制裁
- **可撤销 vs 确认违法**：行为**还存在** → 撤销；已解除 / 无撤销内容 → 确认违法
- **直接损失 vs 间接损失**：赔偿只赔直接（原料变质），不赔间接（订单违约）
- **增加诉讼请求**：起诉状副本送达被告后提出 → 不予准许

### （4）法言法语术语（须会写）
暂时性控制、直接损失、起诉状副本送达被告后、按日连续处罚、先补偿后搬迁、职权法定、比例原则、信赖保护

### （5）易错点（避坑清单 · 练到条件反射，见 `法考主观题避坑清单.md`）
- 已解除行为判**确认违法**非撤销
- 债权人一般**无**原告资格（除非法律明文）
- 适用法律错误应**撤销**非确认违法
- 庭审发现新罪 → 通知检方变 / 补 / 追起诉，非发回重侦
- 强制录音录像仅「检监指居无死重」必须录，普通案可录可不录

---

## 一句话使用纪律
刷题前扫一遍本表 → 写题时：框架走五步、定性走分水岭、术语写法言；**条号与具体文字留到写完去速查卡 / 法规库查**，不占用脑容量去背。
