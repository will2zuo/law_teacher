## 一、科目总览

### 1.1 科目特点

| 维度 | 说明 |
|------|------|
| **考查形式** | 主观题**选做题之一**（与商法二选一），考生可任选其一作答 |
| **分值与地位** | 选做部分约28分；行政法案例以案例为基础设问，将行政法体系中若干环节抽出集中考查 |
| **案例特点** | 基本上是一个**大型选择题**——选做题由于选项限制，只能考查4个角度，案例题则可以有很多个设问 |
| **套路化程度** | **极高**。行政法主观题高度程式化，核心方法论是"**行政行为合法性审查**"思路（主体→权限→内容→程序） |
| **知识覆盖** | 客观题与主观题重合度高，大部分知识点仅在客观题中考查；主观题聚焦**高频核心考点** |

### 1.2 核心方法论

**"找主体、看行为、分阶段、辨诉求"四步法：**

1. **找主体** —— 确定谁作出了行政行为（行政机关？授权组织？受委托组织？内设机构？）
2. **看行为** —— 定性行政行为的类型（处罚？许可？强制？确认？征收？）
3. **分阶段** —— 区分不同阶段的法律关系（作出阶段、复议阶段、诉讼阶段）
4. **辨诉求** —— 明确原告的诉讼请求是什么（撤销？确认违法？赔偿？）

**合法性审查五要件（万能模板）：**
```
① 主体合法（是否有法定职权）
② 事实清楚、证据确凿
③ 适用法律、法规正确
④ 符合法定程序
⑤ 无滥用职权和明显不当
```

### 专题一 行政法概述（书p1-9 / PDF p8-16）

#### 第一节 行政法的基本概念及体系
- **行政的概念**：行政 = 管理；"行政"存在于所有社会组织当中；**公共行政**是行政法调控的对象
- **行政法的法律渊源**（8类，效力层级由高到低）：
  1. 宪法 → 2. 法律（全国人大及其常委会）→ 3. 行政法规（国务院）
  4. 部门规章（国务院下属部门）→ 5. 地方性法规（省级/设区的市人大）
  6. 地方政府规章（省级/设区的市政府）→ 7. 其他规范性文件 → 8. 国际条约/协定
  9. 法律解释
- **规范性文件的效力层次**：上位法优于下位法；人大优于政府；省法规 > 省规章 > 市法规 > 市规章

#### 第二节 行政法的基本原则（★★★ 高频考点）
| 原则 | 核心内涵 | 主观题关键词 |
|------|----------|-------------|
| **合法行政原则** | 法律优先（不得抵触）+ 法律保留（无法律依据不作为）；"无授权则无行政，有授权才有行政" | 超越职权、无法律依据 |
| **合理行政原则** | 公平公正（平等对待）、考虑相关因素、比例原则（三方面：合目的性、适当性、损害最小） | **比例原则是重中之重** |
| **程序正当原则** | 行政公开（过程公开+结果公开）、公众参与（听证等）、公务回避 | 听证程序、回避 |
| **高效便民原则** | 行政效率（积极履职、遵守时限）+ 当事人便民（执法为民） | 时限要求、一站式办理 |
| **诚实守信原则** | 信息真实全面 + 保护信赖利益（非因法定事由并经法定程序，不得撤回变更已生效决定） | **信赖保护** |
| **权责统一原则** | 行政效能 + 行政责任（有权必有责、用权受监督、违法要赔偿） | 权责一致 |

> **【注意】** 比例原则在行政许可中体现为许可制度的精简化；在行政处罚中体现为过罚相当；在行政强制中体现为禁止使用断水断电等方式。

### 专题二 行政主体（书p10-16 / PDF p17-23）

#### 一、行政主体的概念
- 定义：对外以自己名义实施国家行政管理职能并承受一定法律后果的国家行政机关和社会组织
- **两大功能**：（1）解决控权对象问题；（2）实质上是公法意义上的法人
- **关键判断标准**：只要该主体在某法律关系中居于不平等的地位，对外开展行政活动，并承担相应的公法责任，此时即为行政主体

#### 二、行政机关
- **一般行政机关**（五级）：国务院 → 省/自治区/直辖市 → 设区的市 → 县 → 乡
- **专门行政机关**：行使某类专门行政管理职能的职能部门（公安、教育、卫健等），能以自己名义独立开展行政活动

#### 三、被授权组织 vs 受委托组织（★★★ 必考区分）
| 对比项 | 被授权组织 | 受委托组织 |
|--------|-----------|-----------|
| 法律依据 | 法律、法规、规章授权 | 行政机关委托 |
| 主体资格 | **有**（独立被告） | **无**（委托机关为被告） |
| 后果 | 以自己名义承担法律责任 | 由委托机关承担 |
| 对象 | 机构、组织、个体 | 机关、机构、组织、个体 |

#### 四、行政主体的判定公式
> **"行政主体 = 行政诉讼被告"** —— 这是贯穿全书的**核心等式**

### 专题三 具体行政行为概述（书p17-35 / PDF p24-42）

#### 第一节 具体行政行为的概念
- **定义**：行政主体依法就特定事项对特定的公民、法人和其他组织权利义务作出的单方行政职权行为
- **四大构成要素**（判断是否为具体行政行为的标准）：

| 要素 | 含义 | 判断要点 |
|------|------|----------|
| **(一) 特定性** | 约束对象特定 | 关键看行为作出时约束对象是否特定；名称不重要，**内容是否针对确定性的个体**才是关键 |
| **(二) 处分性** | "必然影响当事人权利义务" | 主观上有影响意图 + 客观上产生实际影响；**没有实际影响 = 不属于具体行政行为** |
| **(三) 外部性** | 对外发生法律效果 | 内部行为（如人事任免）不可诉 |
| **(四) 单方性** | 行政机关单方意志决定 | 不需要相对人同意即可成立 |

> **排除的具体行政行为类型**：
> - 暴力侵权行为（事实行为）→ 国家赔偿但不属具体行政行为
> - 行政指导（柔性、建议性质）→ 不可诉
> - 重复处理行为 → 不可诉
> - 抽象行政行为 → 一般不可直接起诉

#### 第二节 具体行政行为的成立和效力
- 成立条件 → 生效条件 → 合法性评价 → 有效/无效/可撤销/可变更

### 专题四 行政许可（书p36-53 / PDF p43-60）

#### 一、行政许可的概念
- **核心要素**："**一般禁止的解除**"——当事人在没有被准予从事某项特定活动之前，处于被禁止的状态
- **四大特征**：
  1. **依申请性**（必须以当事人申请为前提）
  2. **授益性**（赋予资格或能力，是一种授益性行政行为）
  3. **要式性**（必须以书面形式作出）
  4. **外部性**（内外看身份：内部审批 ≠ 行政许可）

#### 二、行政许可 vs 行政确认（常混考点）
| | 行政许可 | 行政确认 |
|--|---------|---------|
| 性质 | 赋予**新的权利** | 对**已经存在**的权利义务予以认定证明 |
| 是否赋权 | 是（"无中生有"） | 否（对既有事实的评判和宣告） |
| 典型例子 | 驾驶证、营业执照 | 户籍登记、婚姻登记、学位证书 |

#### 三、行政许可的实施方式（★★★ 高频出题）
| 方式 | 内容 | 注意 |
|------|------|------|
| 一个窗口对外 | 统一受理/送达 | "一个窗口对外" |
| **权力所有/部分转移** | **集中许可** | 权力实质性转移给某个机关 |
| **权力所有/部分不移转** | **一站式审批**（许可大厅/联合许可） | 形式集中，权力不变 |
| **并联式审批**（统一办理） | 某一许可涉及多个部门，主办机关统一受理后转其他部门 | 只需向一个机关提交申请材料 |

### 专题五 行政处罚（书p54-86 / PDF p61-93）

#### 一、行政处罚的概念与基本特征
- **定义**：行政机关依法对违反行政管理秩序的公民、法人或者其他组织，以减损权益或者增加义务的方式予以惩戒的行为
- **基本特征**：
  1. 是行使国家惩罚权的活动（区别于内部纪律处分）
  2. 针对**外部**的公民、法人或其他组织的违法行为
  3. 是维护行政管理秩序的**具体行政行为**
  4. **惩戒性**（目的=惩戒，方式=减损权益/增加义务）——这是与行政强制的**根本区别**

#### 二、行政处罚的种类
| 类别 | 种类 | 说明 |
|------|------|------|
| **声誉罚** | 警告 | 只有精神上的制裁作用（书面） |
| **财产罚** | 罚款、没收违法所得/非法财物 | 最常见 |
| **行为罚（资格罚）** | 责令停产停业、暂扣/吊销许可证照 | 限制或剥夺从事某种活动的资格 |
| **人身自由罚** | 行政拘留 | **仅限于公安机关**执行 |
| **其他** | 法律/行政法规规定的其他处罚 | 如通报批评、降低资质等级等（2021年新增） |

> **【注意】** 行政处罚与刑罚的折抵：行政拘留折抵拘役/有期徒刑；罚款折抵罚金。但**没收不能与没收相折抵**。

#### 三、行政处罚的设定（★★★）
- 法律 → 可设定各种处罚（**限制人身自由只能由法律设定**）
- 行政法规 → 除限制人身自由以外
- 地方性法规 → 除限制人身自由、吊销企业营业执照以外
- 规章 → 仅可设定警告和一定数量的罚款

#### 四、治安管理处罚（《治安管理处罚法》）（专题五第四节，单独重点）
- 公安机关专属处罚领域
- 与一般行政处罚的关系：特别法与一般法

### 专题六 行政强制（书p87-112 / PDF p94-119）

#### 一、行政强制执行的概念和特征
- **定义**：行政机关或者行政机关申请法院对不履行行政决定的公民、法人或者其他组织，依法强制其履行义务的行为
- **三大特征**：
  1. **与行政强制措施相同**——"短兵相接"，直接施加强制力
  2. **依附性**——必须有**基础决定**（具体行政行为）为前提
  3. **目的的执行性**——目的是迫使履行义务或达到与履行义务相同的状态

#### 二、行政强制措施的概念和特征
- **定义**：行政机关在行政管理过程中，为制止违法行为、防止证据损毁、避免危害发生、控制危险扩大等情形，依法对公民的人身自由实施暂时性限制，或者对公民、法人和其他组织的财物实施暂时性控制的行为
- **三大特征**：
  1. **强制性**——物理性限制（限制人身或改变财产状态），相对人只能服从
  2. **目的的非惩罚性**——**控制与预防**（不是惩罚！这是与行政处罚的根本区别）
  3. **行为的暂时性**——一旦目的实现，应当解除

> **行政强制措施 vs 行政强制执行 vs 行政处罚 的关键区别**：
> - 措施 = 暂时性控制（预防目的，非惩罚）
> - 执行 = 强制实现基础决定的内容（执行目的）
> - 处罚 = 惩戒（惩罚目的）

#### 三、行政强制的种类和设定
- **行政强制措施**：限制人身自由、查封、扣押、冻结
- **行政强制执行**：加处罚款/滞纳金、代履行、划拨存款/汇款、拍卖/依法处理财物等
- **设定权限**：法律/行政法规可设定；地方性法规**仅可**设定查封、扣押措施

### 专题七 其他具体行政行为（书p113-117 / PDF p120-124）

#### 一、行政确认
- **定义**：行政机关依法对公民、法人或其他组织的法律地位、法律关系或有关法律事实进行甄别和给予确定、认定、证明、予以宣告的行政行为
- **三大特征**：既存性、宣示性和保护性、证据性
- **典型形式**：工伤认定、排污合格认定、文化主管部门鉴定、交通事故责任认定书等

#### 二、行政裁决
- **定义**：行政机关在其行政职权范围内，对平等主体之间发生的民事纠纷进行审查并作出裁断的具体行政行为
- **典型领域**：《商标法》《土地管理法》等法律规定了行政裁决
- **优势**：具有司法色彩，高效、专业、成本低、行政权威性强

### 专题八 政府信息公开（书p118-127 / PDF p125-134）

#### 一、政府信息公开制度概述
- **政府信息的范围**：
  - 必须是在**履行行政管理职能过程中制作或获取**的信息
  - **不包括**：党务信息、立法信息、公安侦查情况等司法信息
  - **包括**：履行职责过程中获取的其他行政机关制作的政府信息
- **公开原则**："**谁制作、谁公开**""谁保存、谁公开"

#### 二、政府信息公开的主体
- **行政机关**：制作该信息的行政机关负责公开
- **公民/法人/其他组织获取的信息**：由保存该信息的行政机关负责公开
- **特殊规则**："**一手来源负责公开原则**"——谁最初获取，谁负责公开

### 专题九 行政争议法总论（书p128-135 / PDF p135-142）

#### 一、行政诉讼概述
- **定义**：法院应公民、法人和其他组织的请求，通过审查行政行为合法性的方式，解决特定范围内的行政争议，并为当事人提供救济的活动
- **三大诉讼共同点**：都是国家审判制度的基本形式之一
- **行政诉讼的特殊性**：
  1. 解决**特定范围内**的行政争议（保护公民、法人和其他组织的合法权益）
  2. 依照**民诉程序**以脱胎于民事诉讼制度（但存在诸多差异）
  3. 通过审查**行政行为合法性**的方式解决行政争议
  4. 不仅解决纠纷，还要**监督行政机关依法行使行政职权**

#### 二、行政复议概述
- **定义**：行政机关根据上级行政机关对下级行政机关的监督权，在当事人的申请和参加下，按照行政复议程序对行政行为的合法性和适当性进行审查，作出裁决解决行政争议的活动
- **性质**：一种借助上级机关的**权威性和专业性**，实现行政机关内部纠错和内部监督的**准司法活动**

> **行政诉讼 vs 行政复议的核心区别**：诉讼是**外部监督**（司法机关），复议是**内部监督**（上级行政机关）

### 专题十 行政诉讼参加人（书p136-165 / PDF p143-172）

#### 一、被告的确认（★★★★★ 最高频考点之一）

| 行为主体 | 被告 |
|----------|------|
| 作出行政行为的行政机关 | 该行政机关 |
| 法律、法规、规章授权的组织 | 该组织（**被授权组织有被告资格**） |
| 行政机关委托的组织 | **委托的行政机关** |
| 派出机关 | 派出机关本身 |
| 被撤销的行政机关 | 继续行使其职权的行政机关；无继续行使的 → 其所属的人民政府 |
| 经批准的行政行为 | **名义上的**行政机关（对外署名的机关） |
| 内设机构/派出机构 | 有法律授权 → 以自己的名义（例外：种类越权时为其所属机关）；无授权 → 所属机关 |
| 共同行为 | **共同被告**（原告知不同意追加列为第三人） |
| 假共同行为 | 其中的行政主体是被告，非行政主体是第三人 |
| **房屋征收补偿行为** | 作出征收决定的县级以上人民政府确定的房屋征收部门 |
| 大队和支队 | 县交警大队≈县交管局；市交警支队≈市交管局 |
| 政府信息公开案件 | （1）主动公开 → 作出该政府信息公开的行政机关；（2）申请公开 → 收到申请的行政机关 |

#### 二、原告的确认（★★★★）
- **原告资格标准**：认为**自己的合法权益**受到行政行为侵犯的公民、法人或其他组织
- **近亲属**可以提起诉讼（有权提起诉讼的公民死亡时）
- **利害关系**标准：与行政行为有**法律上的利害关系**

#### 三、共同诉讼、第三人、诉讼代理人
- **必要共同诉讼**：同一行政行为涉及多方当事人
- **普通共同诉讼**：同类行政行为
- **第三人**：与被诉行政行为或处理结果有利害关系的公民/法人/其他组织

### 专题十一 行政诉讼的管辖（书p166-173 / PDF p173-180）

#### 一、级别管辖
| 法院级别 | 管辖范围 |
|----------|----------|
| **基层人民法院** | **第一审行政案件原则上均由基层法院管辖**（除法律规定的特殊情况外） |
| **中级人民法院** | （1）**国务院部门**为被告的案件；（2）**县级以上地方政府**为被告的案件；（3）海关处理的案件；（4）社会影响重大的共同诉讼/集团诉讼案件 |
| **高级人民法院** | 本辖区内重大复杂的第一审行政案件 |
| **最高人民法院** | 全国范围内重大复杂的第一审行政案件 |

> **【注意】** "行政机关"只指一般权限政府（县级、市级、省级政府三类），**不包括**地方政府的职能部门（如省公安厅、市司法局等）。省公安厅等为被告时 → 基层法院管辖。

#### 二、地域管辖
- **一般原则**：**原告就被告**（最初作出行政行为的行政机关所在地法院）
- **经复议的案件**：原机关所在地 或 复议机关所在地（选择管辖）
- **不动产案件**：**不动产所在地**专属管辖

#### 三、裁定管辖
- 移送管辖、指定管辖、管辖权转移

### 专题十二 行政诉讼的受案范围（书p174-189 / PDF p181-196）

#### 一、受案范围的确定标准
- **核心标准：行为标准**——只要属于具体行政行为，就必然具有**可诉性**
- **2014年修改后的受案范围**：**"具体行政行为 + 行政合同 + 部分抽象行政行为"**
- **不属于受案范围的**：刑事司法行为、内部行为、国家行为、刑事司法行为等

#### 二、应予受理的案件类型（★★★★）

| 类型 | 说明 | 典型例子 |
|------|------|----------|
| **(一) 行政处罚案件** | 警告、罚款、拘留、没收、吊销许可证照、责令停产停业 | 交警罚单、工商吊销执照 |
| **(二) 行政强制案件** | 强制措施（查封/扣押/冻结）+ 强制执行（拍卖/划拨等） | 强拆、冻结账户 |
| **(三) 行政许可案件** | 许可的拒绝、不予答复、变更/延续/撤回/注销/撤销等 | 不予颁发许可证 |
| **(四) 行政确权案件** | 自然资源所有权/使用权确权决定不服 | 土地/矿藏/山林确权 |
| **(五) 征收/征用案件** | 征收征用决定及补偿决定 | 房屋征收决定 |
| **(六) 不履行法定职责案件** | 申请保护人身权/财产权等合法权益，行政机关不作为 | 报警不出警、申请许可不答复 |

> **【知识点拨】** 某个行为具有可诉性，或者说某个行为属于受案范围，或者说当事人对某个行为有权起诉——**这三个表述内容是一样的**，就是某个行政行为是否属于受案范围的分析。

### 专题十三 行政诉讼程序（书p190-227 / PDF p197-234）

#### 一、起诉和受理

**起诉的一般条件（第49条）：**
1. **原告适格**——是行政行为的相对人以及其他与行政行为有利害关系的公民、法人或其他组织
   - 行政主体不能作为原告
   - 侵犯**原告合法**权益的是行政行为（不是公共利益）
   - **普通公民/法人/其他组织等私主体不能提起公益诉讼**
2. **有明确的被告**——须指明谁为被告
3. **有具体的诉讼请求和事实根据**——"就……起诉"
4. **属于法院受案范围和受诉法院管辖**

**一事不再理（禁止重复起诉）：**
- 同时满足三个条件才构成重复起诉：(1) 当事人相同；(2) 诉讼标的相同；(3) 诉讼请求相同/后诉请求被前诉裁判所包含

#### 二、行政诉讼审理程序
- **一审程序**：开庭审理（原则上公开）
- **简易程序**：适用特定简单案件
- **二审程序**：上诉审理
- **审理中的特殊制度**：缺席判决、先予执行等

#### 三、行政诉讼与其他诉讼交叉案件
- 民行交叉、刑行交叉的处理规则

### 专题十四 行政诉讼证据（书p228-243 / PDF p235-250）

#### 一、行政诉讼证据制度的特点
- **最大差别**：**"不利被告"的价值倾向**——举证责任分配、举证期限、证据调取和证据补充等问题上，鲜明体现"不利被告、偏向原告"的价值倾向
- **两大原因**：
  1. **有证在先**——行政机关作出行政行为时应先取证后裁决
  2. **行政机关处于强势地位**，而公民/法人/其他组织居于被支配的服从者地位

#### 二、证据的概念和要求
- **真实性**：客观存在的事实，具有客观属性
- **关联性**：与待证案件事实之间具有一定的内在联系
- **合法性**：（待补充后续页）

#### 三、举证责任分配（★★★）
- **被告承担主要举证责任**——证明被诉行政行为合法
- **原告承担初步举证责任**——证明起诉符合条件、提出行政赔偿需证明损害事实

### 专题十五 行政诉讼的法律适用（书p244-247 / PDF p251-254）

#### 一、法律适用的含义
- 法院按照法定程序将法律、法规以及法院决定参照的规章具体适用于各种行政案件，对被诉行政行为的合法性进行审查的活动

#### 二、法律适用的规则
| 规则 | 内容 |
|------|------|
| **法律、行政法规与地方性法规** | 行政审判的**依据**（"依据"的含义：法院对行政行为合法进行审查和裁判时，**必须适用**，不能拒绝适用） |
| **规章** | **参照**（法院审理行政案件时可参照引用合法有效的规章；不符合/不完全符合的可以不予适用） |
| **法律适用规则** | 上位法优于下位法、新法优于旧法、特别法优于一般法 |
| **送请有权机关处理** | 冲突规范所涉事项比重较大；有关机关对是否存在冲突有不同意见；应优先适用的法律规范的合法性尚有疑问；按法律适用规则则不能确定如何适用 |

> **"参照"与"依据"的区别关键**："依据"是法院对法律、法规无条件适用；"参照"则是法院对规章享有一定的审查判断权。

### 专题十六 行政诉讼的裁判与执行（书p248-265 / PDF p255-272）

#### 一审判决的8种形式（★★★★★ 核心输出考点）

```
一审判决形式总览：
├── 合法 → 驳回原告诉讼请求
│   ├── 能撤销就撤销（5种情形）
│   │   ├── 给国家/公共利益造成重大损害
│   │   ├── 诉讼中被诉行为已被撤销/变更
│   │   ├── 不具有可撤销内容
│   │   ├── 程序轻微违法但对原告权利不产生实际影响
│   │   └── 无效行政行为
│   └── 不能撤销则确认（处罚显失公正等涉及数额有误可撤销可变）
├── 作为（违法）
│   ├── 能作为就作为：履行判决、给付判决（需被告调查/裁量，判决被告针对请求重新作出处理）
│   └── 不能作为则确认（作为没意义）
└── 不作为（违法）
    ├── 判决履行（被告在一定期限内履行）
    └── 确认违法（履行已无意义）
```

#### 二、具体行政行为合法时的判决形式
- **驳回原告诉讼请求**（"具体行政行为合法 → 驳回胜诉、原告败诉"）
- 五个要件：主体合法、证据确凿、适用法律法规正确、符合法定程序、没有滥用职权/明显不当

#### 三、具体行政行为违法时的判决形式
- **作为违法**：
  - **撤销判决**（能撤销就撤销）：超越职权、主要证据不足、适用法律/法规错误、违反法定程序、滥用职权/明显不当
  - **确认违法判决**（不能撤销时）：给国家/公共利益造成重大损害、不具有可撤销内容、程序轻微违法但不影响实体权利
- **不作为违法**：
  - **履行判决**（被告在一定期限内履行）
  - **确认违法判决**（履行已无意义）

> **【注意】** 与行政复议不同，行政诉讼在被诉行政行为合法时，**并不存在维持判决或确认合法判决**——因为法院是外部的中立第三方主体，不便通过维持判决为行政机关的行为背书。

### 专题十七 行政公益诉讼（书p266-272 / PDF p273-279）

#### 一、原告资格
- **只有检察机关**具有公益诉讼的原告诉讼资格
- **普通公民、法人和其他组织不具有公益诉讼的原告诉讼资格**
- 检察院只能"**据旗呐喊**"（支持起诉），只有在这些组织不提起诉讼的情况下，检察院才可以向法院提起诉讼
- **行政公益诉讼的被告是行政机关**（属于检察院监督对象）

#### 二、受案领域（2021年新增）
生态环境和资源保护、食品药品安全、国有财产保护、国有土地使用权出让等领域负有监督管理职责的行政机关

#### 三、管辖与程序
- **基层检察院**提起 → **基层法院**管辖
- **前置程序**：检察院**不能直接**向法院起诉，必须先向行政机关提出检察建议（必经程序）
- **期限**：行政机关应在收到检察建议书之日起**2个月内**依法履行职责并书面回复；出现国家利益或社会公共利益损害继续扩大等紧急情形的，应在**15日内**书面回复
- **起诉前提**：行政机关**不依法履行职责**的，检察院依法向法院提起诉讼

> **【注意】** 民事公益诉讼是以公告为起诉前提，行政公益诉讼是以**检察建议为起诉前提**。

### 专题十九 行政协议及其诉讼制度（书p273-286 / PDF p280-293）

#### 一、行政协议的概念
- **定义**：行政机关为实现公共利益或者行政管理目标，在法定职责范围内，与公民、法人或者其他组织协商订立的具有行政法上权利义务内容的协议
- **四大要素**：
  1. 必须一方当事人为**行政机关**
  2. 目的是为了实现**行政管理或者公共服务目标**
  3. 内容要素：协议内容必须具有**行政法上的权利义务内容**
  4. 意思要素：协议双方当事人必须**协商一致**

#### 二、识别标准
- **形式标准**：是否发生于履职的行政机关与行政相对人之间的协商一致
- **实质标准**：协议的标的及内容有无行政法上的权利义务，该权利义务取决于是否行使行政权、履行行政职责；是否为实现行政管理目标和公共服务；行政机关是否具有**优益权**

#### 三、行政协议 vs 相关概念的区别
| | 行政协议 | 具体行政行为 | 内部协议 |
|--|---------|------------|---------|
| 性质 | 双方行为（协商一致） | 单方行为 | 内部行为 |
| 相对方同意 | 需要 | 不需要 | N/A |
| 可诉性 | 可诉（行政协议诉讼） | 可诉（行政诉讼） | 不可诉 |

### 专题二十 行政复议制度（书p287-316 / PDF p294-323）

#### 一、行政复议受案范围
- 与行政诉讼受案范围**基本一致**，不赘述
- 但《行政复议法》增加了额外的受案范围（如工伤认定申请的不予受理决定、行政赔偿决定等）

#### 二、行政复议参加人和复议机关
- **申请人**：与行政诉讼原告制度内容一样
- **被申请人**：作出被申请复议的行政行为的行政机关（**行政主体现论**）
- **第三人**：申请人以外的同被申请行政复议的行政行为或者行政复议案件处理结果有利害关系的公民/法人/其他组织
- **复议机关**（2023年大改）：
  - **县级以上地方政府**对本级政府工作部门作出的行政行为不服 → **本级政府**统一行使复议
  - **"谁家孩子谁抱走，地方事务归地方政府，全国事务归部委"**
  - 例外：海关、金融、外汇、国税等实行**垂直领导**的机关 → 上一级主管机关

#### 三、行政复议的一般程序
- 申请 → 受理 → 审理 → 决定
- **复议前置**：特定情形下必须先复议才能起诉（如自然资源权属确认等）

#### 四、行政复议的决定
- 维持决定、撤销/变更/确认违法决定、责令履行决定等

### 专题二十一 国家赔偿（书p317-357 / PDF p324-364）

#### 一、国家赔偿的概念
- **定义**：国家对国家机关及其工作人员**违法行使职权**或**存在过错等原因**造成的损害给予受害人赔偿的制度
- **归责原则变迁**：从单一违法归责原则（旧法）→ **多元归责原则**（2010年后）

#### 二、国家赔偿的归责原则（★★★）

```
国家赔偿归责体系：
违法归责 ──→ 一般行政行为 ──→ 违法归责
                ↓
         过错归责 ──→ 刑事司法行为（逮捕和判决）
                ↓
         结果归责 ──→ 严格按结果论（不论是否违法/过错，只要有损害结果即赔）
```

| 归责原则 | 适用范围 | 标准 |
|----------|----------|------|
| **违法归责** | 一般行政行为 | 行为违法 → 赔偿；未违法但有合理注意义务且无法避免损害结果 → **不赔**（但可用行政补偿） |
| **过错归责** | 刑事司法中的逮捕和判决 | 事实行为适用**过错归责**（以理性第三人的合理注意义务为标准） |
| **结果归责** | 刑事诉讼中**限制人身自由的逮捕和判决** | 只要发生了损害结果（如无罪羁押、无罪判决），**不管此前是否存在违法/过错**，国家均应承担赔偿责任 |

#### 三、行政赔偿
- **构成要件**：侵权行为（职务行为）+ 损害事实 + 因果关系
- **赔偿范围**：人身自由损害（限制人身自由）、生命健康权损害（殴打/违法使用武器警械）、财产权损害
- **赔偿义务机关**：实施侵害的行政机关

#### 四、司法赔偿
- **刑事赔偿**：错误拘留、错误逮捕、再审改判无罪等
- **民事/行政司法赔偿**：违法采取保全措施、错误执行等

#### 五、国家赔偿方式和标准
- 方式：支付赔偿金、返还财产、恢复原状
- 标准：人身自由按日计算、生命健康权按医疗费/残疾/死亡赔偿金计算、财产按直接损失计算

## 四、主观题答题模板速查

### 模板1：行政行为合法性审查（最常用）
```
第一步：定性——该行为属于XX（处罚/许可/强制/确认...）行为
第二步：主体——作出机关是XX，其是否有法定职权？
    ✓ 有 → 主体合法
    ✗ 无 → 越权/无权限 → 违法
第三步：事实与证据——事实是否清楚？证据是否确凿充分？
第四步：法律依据——适用法律/法规是否正确？
第五步：程序——是否符合法定程序？（听证/告知/期限/送达...）
第六步：裁量——是否存在滥用职权或明显不当？
结论：综上，（合法/违法），法院应作出（驳回/撤销/确认违法/履行...）判决
```

### 模板2：被告确认
```
XX行为是由[ ]作出的。
如果[ ]是被授权组织 → 它是被告（有被告资格）
如果[ ]是受委托组织 → 委托它的[行政机关]是被告
如果是经过批准的 → 名义上的机关是被告
如果是内设机构 → 有法律授权以自己名义 → 自己是被告；否则 → 所属机关是被告
```

### 模板3：受案范围判断
```
该行为属于（具体行政行为/行政协议/抽象行政行为附带审查...），
（属于/不属于）行政诉讼受案范围。
理由：（引用具体条款 + 结合案情分析）
如果不属于受案范围 → 法院裁定不予受理/驳回起诉
```

### 模板4：判决类型选择
```
若被诉行为合法 → 驳回原告诉讼请求
若违法 + 作为：
  - 可撤销（5种可撤销情形）→ 撤销判决
  - 不可撤销（给公益造成重大损害/无可撤销内容/程序微瑕）→ 确认违法判决
若违法 + 不作为：
  - 履行仍有意义 → 履行判决
  - 履行无意义 → 确认违法判决
若涉及赔偿 → 可一并提出赔偿请求
```
