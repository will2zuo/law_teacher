# 法考主观题·行政法标准答题模板
## ——以 2024 年万兴公司案（6 问）真题为母本拆解

> 本文档由 2024 年法考行政法真题（万兴公司：特种作业无证上岗→责令整改+现场停产+罚款+复议维持+诉讼）的 6 问及官方参考答案，提炼出**通用标准模板 + 六类题型微模板**。
> 用法：写任何行政法主观题，先判断它属于下面哪类题型，套对应微模板，底层统一走"五步法"。
> 注：本模板为**答题形态范式**，具体法条条号/定性须以当年真题题面与法条为准，开卷可查。

## 二、参考答案的"采分密码"（为什么这样给分）

拆开每问答案，给分逻辑高度一致，本质是**"结论分 + 法条/概念分 + 归入分 + 闭合分"**四块：

1. **结论分（1–2分）**：每问第一句就是结论——"属于行政强制措施""不予准许""共同被告""可以加处罚款并申请法院执行"。**结论必须占首句**，不绕弯。
2. **概念/法条分**：必引《XX法》第X条，且把法条**拆成可采分的小点**。如 Q1 强制措施定义被拆成"暂时性限制人身自由 0.5 分 + 暂时性控制财物 0.5 分"；Q3 拆成"复议维持 0.5 + 共同被告 0.5"。
3. **归入分**：把法条要件套到本案事实。如 Q1"本案是基于重大隐患的暂时性措施，具临时性紧急性，目的为预防危险而非最终处理"；Q2"庭审中增加请求→超过增加诉讼请求的截止时间"。
4. **闭合分**：反向排除干扰项或落到处理结论。Q1 末句"故该行为属于行政强制措施，**不属于行政处罚**"；Q2 末句"所以法院应当**不予准许**"。

→ 印证铁律：**真题答案从不"列要点"，全是"结论→法条→要件→归入→闭合"五步闭环**。无条号 = 无"有法可依"证明 = 丢分。

## 三、通用标准模板（五步法·万能骨架）

```
① 结论     ：定性 / 判断 / 处理方式，一句话占首句（占分最高）
② 法条     ：必引《XX法》第X条（开卷可查，但答案须写条号，条号即采分点）
③ 要件展开 ：把法条拆成可采分的小点，用 ①②③ 分层
④ 归入本案 ：将要件逐一对应题干事实（"本案中…符合…"）
⑤ 闭合     ：排除干扰项（"故不属于XX"）或落到判决/处理结论
```

⚠️ **三条铁律**
- 法条条号是采分点，不是装饰。无条号 = 知识无法被阅卷人确认 = 丢分。
- 每个定性/违法点必须**落到后果**（撤销/确认违法/不予准许/驳回…），不能只列事实。
- 术语必须法言法语（"暂时性控制""起诉状副本送达被告后""按日连续处罚"），不用口语。

## 四、六类题型微模板（对应本案 6 问）

### 【题型A：行为性质定性】—— 对应 Q1
**模板**：结论（属XX行为） + 概念（引《XX法》定义，拆要件给分点） + 本案归入（为何符合要件） + 反排（为何不属干扰项）。
**示范**：
> 属于行政强制措施。行政强制措施是行政机关在行政管理过程中，为制止违法行为、防止证据损毁、避免危害发生、控制危险扩大等情形，依法对公民人身自由实施暂时性限制，或对公民、法人、其他组织的财物实施暂时性控制的行为（《行政强制法》第2条）。本案中《现场处理措施决定书》基于该公司存在重大事故隐患而采取，具有临时性和紧急性，目的为预防或制止危险状态及不利后果，而非对违法事实的最终认定和处理，故属行政强制措施，**不属于行政处罚**。

### 【题型B：程序法时间点判断】—— 对应 Q2
**模板**：结论（准予/不予准许） + 法条（引程序法条及关键时间点） + 本案事实归入（何时提出→超期/未超期） + 闭合。
**示范**：
> 不予准许。依《行诉解释》第70条，起诉状副本送达被告后，原告提出新的诉讼请求的，人民法院不予准许，但有正当理由的除外。本案一审庭审中万兴公司增加诉讼请求（审查并撤销现场处理决定），超过了增加诉讼请求的截止时间，故法院应当不予准许。

### 【题型C：被告/管辖确定】—— 对应 Q3
**模板**：先定复议机关（引复议法管辖条） + 再定被告（引行诉法§26 复议维持共同被告） + 结论（列明机关）。
**示范**：
> （1）依《行政复议法》第24条，对人民政府工作部门（本题丙区应急管理局）的行政行为不服，由县级以上地方各级人民政府管辖，故复议机关为丙区政府。（2）依《行政诉讼法》第26条第2款，复议机关决定维持原行政行为的，作出原行政行为的行政机关和复议机关是共同被告。故本案被告为丙区应急管理局和丙区政府。

### 【题型D：行政处理/执行措施】—— 对应 Q4
**模板**：结论（处理方式） + 法条分项（引处罚法/强制法） + 闭合。
**示范**：
> 依《行政处罚法》第72条：（1）逾期不缴纳罚款的，区应急管理局可以每日按罚款数额的百分之三加处罚款，加处罚款数额不得超出罚款数额；（2）区应急管理局无直接强制执行权，可依照《行政强制法》申请人民法院强制执行。
**铁律**：行政机关大多**无直接强制执行权**，记住"加处罚款 + 申请法院执行"二元结构。

### 【题型E：复议/诉讼程序规则】—— 对应 Q5
**模板**：结论（应/可以XX） + 法条分项（引程序法条，区分"应/可以/例外"） + 例外。
**示范**：
> 依《行政复议法》第49、50条：（1）普通程序审理的复议案件，复议机构应当当面或通过互联网、电话等方式听取当事人意见并记录在案；因当事人原因不能听取的，可以书面审理。（2）审理重大、疑难、复杂案件，复议机构**应当**组织听证；复议机构认为有必要或申请人请求听证的，复议机构**可以**组织听证。

### 【题型F：抽象行为/裁量基准规则】—— 对应 Q6
**模板**：结论（可制定 + 应公布） + 法条（引处罚法§34） + 要件。
**示范**：
> 依《行政处罚法》第34条，行政机关可以依法制定行政处罚裁量基准，规范行使行政处罚裁量权；行政处罚裁量基准**应当向社会公布**。

## 五、对照你（用户）的答题短板

你之前甲公司查封案三问答对考点但输出偏"要点罗列"，差距恰在本模板的反面，须重点补：

| 你的短板（来自查封案批改） | 本真题模板如何纠正 |
|---|---|
| 缺"②法条条号"——三问无一句条号 | 本真题每问必引条号，模板②是采分核心，无条号即丢分 |
| 缺"⑤闭合"——列完违法点不落判决 | Q1末句"不属于行政处罚"、Q2末句"不予准许"都是闭合；你查封案Q3把已解除行为错判"撤销"正是无闭合意识 |
| 术语不够法言法语 | 本真题用"暂时性控制""起诉状副本送达被告后""按日连续处罚"等专有词，模板要求同款精度（"实际损失"→"直接损失"） |

**记忆钩子**：写成答案前先默念——**"结论有没有？条号有没有？要件拆没拆？本案套没套？结尾闭没闭？"** 五问全过才动笔。
