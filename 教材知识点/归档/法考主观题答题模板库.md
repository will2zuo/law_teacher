# 法考主观题答题模板库（踩分点精准版）

> 基于五科知识框架（孟献贵民法 / 柏浪涛刑法 / 左宁刑诉 / 戴鹏民诉 / 李佳行政法）的高频考点提取。
> 用途：考场上往模板里"填案情"，确保每层踩分点都写到、法条/制度定位准确、不漏要件。
> 重要说明：本库为"答题骨架 + 踩分地图"，不是标准答案。最终结论必须以案件事实和最新法条为准。
> 法条序号以考试当年《法条汇编》/最新立法为准，模板中标注的条号仅供参考，正式作答前请核对。

## 〇、通用踩分铁律（五科通用，先背熟）

1. **结论先行**：每问第一句给结论（"成立/不成立""合法/违法""构成/不构成"），别让阅卷人找。
2. **法条/制度定位**：结论之后立即点出依据的制度或法条（"依《民法典》第X条""依非法证据排除规则"）。
3. **要件拆解 + 事实归入**：把该请求的构成要件逐条列出，再把案情事实逐个"套进去"（这是你目前最大的提分空间）。
4. **分层说理**：多个主体/多个可能请求权，必须分点、分段、逐个排除，别搅成一团。
5. **辨析意识**：题目埋的"陷阱"往往是合法 vs 违法、有权 vs 无权、此罪 vs 彼罪，要点出"若…则…"的辨析层。
6. **法言法语**：用规范术语（物权人、合同相对性、违法阻却、先诉抗辩权、上诉不加刑…），忌口语化。

> 你的诊断病灶是"结论对、输出弱"。以上 6 条，每写一题就按它自查一遍，比多做三道题管用。
> 行政法题的具体执行范式（五步法 + 六类题型微模板）见 **模板 20**；它是把"要点罗列"升级为"法言法语分析"的答题引擎。

## 一、民法（孟献贵 · 请求权基础）

### 模板 1：担保制度综合（10/10 年必考）

**【考点定位】** 从属性 + 不可分性 + 物上代位 + 共同担保 + 保证 vs 债务加入。

**【踩分步骤】**
1. 定性担保类型：人保（保证）/ 物保（抵押质押留置）/ 金钱担保（定金）/ 非典型（让与担保、所有权保留）。
2. 从属性：主债权有效/无效/转让/部分消灭 → 担保随之（主合同无效则担保合同无效）。
3. 不可分性：主债权被分割或部分转让 → 担保物权仍担保全部债权。
4. 物上代位性：担保物毁损、灭失、被征收 → 保险金/赔偿金/补偿金上继续存在担保物权。
5. 共同担保（人保+物保并存）：先看约定；无约定时，债务人自己提供物保的，债权人应先就该物保实现债权；第三人提供物保的，债权人可就物保或人保择一行使。混合担保中担保人之间追偿：有约定从约定，无约定原则上无追偿权（《担保制度解释》第13条有例外，需核对）。
6. 保证 vs 债务加入识别：是否明确"保证"字样；是否有从属性/补充性（先诉抗辩权）；加入人是否对债务履行有自身利益。

**【必写采分点】** 从属性、不可分性、物上代位性三词必出；共同担保"先看约定，无约定债务人物保优先"；保证有先诉抗辩权、债务加入无。

**【常见失分点】** 只写"担保有效"不拆三性；混淆保证与债务加入；遗漏共同担保内部追偿规则。

**【一句式示范】** "该担保具有从属性（主债权X则担保X）、不可分性（主债权部分转让不影响担保全部）、物上代位性（标的物灭失后及于代位物）；人保与物保并存，无约定时先就债务人自身物保受偿；甲之承诺属保证（有先诉抗辩权）/ 债务加入（并列债务人）。"

### 模板 2：合同效力多层判断（有权/无权处分 + 善意取得）

**【考点定位】** 合同效力独立判断 + 物权变动 + 善意取得辨析（9/10 年）。

**【踩分步骤】**
1. 先判处分权状态：出让人是有权处分还是无权处分。
2. 合同效力独立判断：**无权处分订立的合同有效**（《民法典》第597条），处分权欠缺影响的是物权能否变动，不影响合同效力。
3. 物权变动判断：
   - 有权处分 + 有效合同 + 交付/登记 = 继受取得；
   - 无权处分 + 有效合同 + 交付/登记 + 相对人善意、合理价格、已公示 = **善意取得（原始取得，《民法典》第311条）**。
4. 辨析层：点出"若甲为所有权人则丙继受取得，不适用善意取得；若甲无权处分则丙善意取得"——这是加分点。
5. 法律后果：未取得所有权的一方只能向出让人主张违约责任/缔约过失。

**【必写采分点】** "无权处分合同有效"、善意取得三要件（善意+合理对价+公示）、继受取得 vs 原始取得区分。

**【常见失分点】** 误以为"无权处分合同无效"；善意取得漏写"合理价格"或"登记/交付"；不点辨析层。

**【一句式示范】** "甲无权处分，但买卖合同有效；丙善意、支付合理对价且已交付，依第311条善意取得所有权（原始取得）；乙未取得所有权，只能请求甲承担违约损害赔偿。"

### 模板 3：合同解除 + 违约责任 + 损害赔偿（含违约金调整）

**【考点定位】** 解除权 + 违约责任形态 + 损害赔偿计算 + 违约金调整（9/10 年）。

**【踩分步骤】**
1. 解除权基础：法定解除（根本违约致合同目的不能实现，《民法典》第563条）/ 约定解除 / 经催告合理期限仍不履行。
2. 解除权行使：通知到达生效；异议期；解除后未履行的终止履行。
3. 违约责任形态：继续履行 / 损害赔偿 / 违约金 / 定金（任选，注意不能并用冲突）。
4. 损害赔偿：填补原则；可得利益损失（替代交易法/市场价格法/差额法）；可预见性规则（《民法典》第584条）；减损义务。
5. 违约金调整：约定违约金过分高于损失（一般以超损失30%为参考）可请求调低；低于损失可请求调高（《民法典》第585条）。
6. 解除后果：依第566条，已履行的可请求恢复原状或赔偿；违约责任不因解除而消灭。

**【必写采分点】** 根本违约→法定解除；违约金"过高调低/过低调高"；解除不消灭赔偿请求权（566条）。

**【常见失分点】** 只写"违约责任"不落实形态；混淆定金与违约金并用；漏写解除后损害赔偿仍存续。

**【一句式示范】** "甲根本违约致合同目的不能实现，乙依第563条解除合同；解除后请求甲损害赔偿（可得利益依替代交易法计算，受可预见性限制）；约定违约金过分高于实际损失，可请求法院调低。"

## 二、刑法（柏浪涛 · 二阶层）

### 模板 4：犯罪成立二阶层审查（通用底盘，每题必走）

**【考点定位】** 客观要件 → 主观要件 → 违法阻却 → 责任阻却。

**【踩分步骤】**
1. 客观要件：是否存在行为、结果、因果关系（行为与结果之间有无因果关系，介入因素两步走：是否异常 + 谁作用大）。
2. 主观要件：故意（直接/间接）或过失（疏忽大意/过于自信）；事实认识错误（具体/抽象/事前故意）。
3. 违法阻却事由：正当防卫（起因/时间/意思/对象/限度）、紧急避险、被害人承诺——若存在则不法排除。
4. 责任阻却事由：责任年龄、责任能力、违法性认识可能性、期待可能性。
5. 结论：依次给出"是否成立犯罪、何罪、形态"。

**【必写采分点】** 四阶层一步不跳；因果关系介入因素分析；正当防卫五要件。

**【常见失分点】** 跳过客观要件直接写主观；遗漏违法/责任阻却；把"假想防卫"误判为故意犯罪（应为过失或意外）。

**【一句式示范】** "客观上甲实施XX行为致XX结果，因果关系成立；主观为间接故意；无违法阻却事由；具有责任能力，故甲构成X罪（既遂/未遂）。"

### 模板 5：共同犯罪（与形态、罪数结合的平台）

**【考点定位】** 正犯优先、共犯从属性、承继共犯、脱离、片面共犯、实行过限。

**【踩分步骤】**
1. 找正犯：谁实施了构成要件行为（部分实行、全部责任）。
2. 共犯从属性：教唆犯、帮助犯的存在以正犯行为为前提。
3. 主观意思联络：是否共同犯罪故意；片面共犯（一方知情他方不知）需展示观点。
4. 参与时间：承继的共犯（中途加入，对加入后行为负责）；共犯脱离（须消除自身行为的因果贡献方免责）。
5. 实行过限：超出共同故意的部分由实行者独自负责。
6. 犯罪形态从属性：共犯形态从属于正犯（正犯未遂则共犯未遂）。

**【必写采分点】** "正犯优先""部分实行全部责任""承继共犯只负加入后责任""过限部分个人担"。

**【常见失分点】** 不区分正犯/共犯；漏写承继共犯的责任边界；把过限行为算到全体头上。

**【一句式示范】** "乙为正犯，甲为帮助犯（共犯从属性）；甲中途退出但未消除因果贡献，不成立脱离，仍对全部负责；丙的XX行为超出共同故意，属实行过限，由丙独自担责。"

### 模板 6：财产犯罪辨析（盗窃/抢夺/抢劫/诈骗/敲诈勒索）

**【考点定位】** 占有转移判断 + 手段区分 + 处分意识。

**【踩分步骤】**
1. 先定占有：财物由谁占有（合法占有亦保护）；行为人是否打破/建立占有。
2. 盗窃罪：转移占有 + 平和手段（非暴力胁迫）+ 非法占有目的。
3. 抢夺罪：对物实施暴力、可能对人发生危险。
4. 抢劫罪：暴力/胁迫/其他方法当场取财；转化抢劫（犯盗抢骗诈，为窝赃/拒捕/毁证当场使用暴力，第269条）。
5. 诈骗罪：行为人欺骗 → 被害人陷入错误 → 有处分意识与处分行为 → 交付财物（三角诈骗：被害人非所有权人但有权处分）。
6. 敲诈勒索：威胁/要挟 → 被害人恐惧 → 交付财物。
7. 辨析核心：有无处分意识（诈骗 vs 盗窃）、有无暴力胁迫（抢劫/敲诈 vs 盗窃）。

**【必写采分点】** 盗窃"平和转移占有"、诈骗"处分意识+处分行为"、抢劫"暴力+当场"、转化抢劫269条。

**【常见失分点】** 把"欺骗交付"写成盗窃；漏三角诈骗；抢劫与敲诈勒索的暴力程度/当场性混淆。

**【一句式示范】** "甲以欺骗使乙陷入错误并基于处分意识交付财物，构成诈骗罪（非盗窃，因乙有处分行为）；若乙未陷错误而甲趁不备取走，则为盗窃。"

### 模板 7：犯罪停止形态（预备/未遂/中止/既遂）

**【考点定位】** 形态排斥关系 + 中止自动性。

**【踩分步骤】**
1. 既遂：齐备全部构成要件（如盗窃取得控制、诈骗取得财物）。
2. 未遂：已着手实行 + 意志以外原因 + 未得逞。
3. 预备：为犯罪准备工具、制造条件，尚未着手。
4. 中止：自动放弃或自动有效防止结果（自动性 + 中止行为 + 有效性）；若已着手后中止仍成立中止。
5. 排斥关系：既遂排斥未遂/中止；同一犯罪只能处一种形态。

**【必写采分点】** 中止"自动+有效防止结果"、未遂"意志以外+未得逞"、预备"未着手"。

**【常见失分点】** 把"惊动后逃跑"误判中止（非自动）；漏写中止须有效防止结果。

**【一句式示范】** "甲已着手但因意志以外原因未得逞，成立未遂；若甲自动放弃并送医防止死亡结果，则成立中止（有效防止）。"

## 三、刑事诉讼法（左宁 · 法条定位）

### 模板 8：非法证据排除（几乎每年必考）

**【考点定位】** 排除范围 + 启动 + 证明责任 + 后果。

**【踩分步骤】**
1. 排除范围：
   - 犯罪嫌疑人供述：刑讯逼供/以暴力威胁等非法方法收集 → 排除；
   - 证人证言、被害人陈述：暴力、威胁等非法方法 → 排除；
   - 书证、物证：取得明显违反法定程序、可能严重影响司法公正且不能补正/作出合理解释 → 排除；
   - 重复性供述：刑讯逼供后无换人换环境等的重复供述一并排除（《严格排除非法证据规定》）。
2. 启动：依申请（被告人/辩护人，庭审前或庭审中提出，提供线索/材料）或法院依职权。
3. 证明责任：检方对取证合法性承担举证责任（出示讯问笔录、录音录像、体检记录等）。
4. 程序：庭前会议可先行调查；庭审中当庭调查；不能排除非法性的，不得作为定案根据。
5. 后果：被排除的证据不得作为起诉/判决依据。

**【必写采分点】** 刑讯逼供所得供述绝对排除；物证书证"严重违法+不能补正"才排除；证明责任在检方；重复性供述规则。

**【常见失分点】** 混淆"供述"与"物证"排除门槛；忘写证明责任在检方；漏重复性供述。

**【一句式示范】** "甲供述系刑讯逼供所得，依非法证据排除规则绝对排除，检方应就取证合法性举证，不能排除的不得作为定案根据；其后在无换人换环境的重复供述一并排除。"

### 模板 9：逮捕条件（强制措施核心）

**【考点定位】** 证据条件 + 刑罚条件 + 社会危险性条件。

**【踩分步骤】**
1. 证据条件：有证据证明有犯罪事实（有证据证明发生了犯罪、是嫌疑人实施、证据已查证属实）。
2. 刑罚条件：可能判处徒刑以上刑罚。
3. 社会危险性条件：采取取保候审不足以防止发生社会危险性（如可能实施新罪、危害安全、毁灭证据、打击报复、自杀逃跑）。
4. 特殊类型：
   - 径行逮捕：可能判处10年以上的；曾经故意犯罪；身份不明。
   - 转化逮捕：被取保候审/监视居住者违反规定情节严重。
5. 羁押必要性审查：捕后可依申请/依职权审查是否继续羁押。

**【必写采分点】** 三条件并列、缺一不可；径行逮捕三情形；社会危险性是核心判断点。

**【常见失分点】** 漏社会危险性条件；混淆径行逮捕与一般逮捕；忘羁押必要性审查。

**【一句式示范】** "逮捕须同时满足：有证据证明有犯罪事实、可能判徒刑以上、取保不足以防社会危险性；甲可能判10年以上，属径行逮捕，无需再证社会危险性。"

### 模板 10：程序违法后果（二审/审判监督）

**【考点定位】** 程序违法 → 撤销原判发回重审；上诉不加刑；全面审查。

**【踩分步骤】**
1. 一审违反法定程序（如公开审判、回避、审判组织不合法、剥夺辩论权、遗漏当事人）→ 二审应裁定撤销原判、发回重审。
2. 事实不清/证据不足 → 可裁定撤销发回，或查清后改判。
3. 二审原则：全面审查（不受上诉/抗诉范围限制）；上诉不加刑（仅有被告人上诉时不得加重）。
4. 审判监督：生效裁判有法定事由（新证据、主要证据不足、伪造、法律适用错误等）→ 再审。

**【必写采分点】** 程序违法→发回重审（237条）；上诉不加刑；全面审查。

**【常见失分点】** 把"事实不清"与"程序违法"后果混同；漏上诉不加刑的"仅被告人上诉"前提。

**【一句式示范】** "一审法院审判组织不合法，属严重违反法定程序，二审应撤销原判、发回重审；本案仅有被告人上诉，须遵循上诉不加刑原则。"

## 四、民事诉讼法（戴鹏 · 六步拆题）

### 模板 11：管辖判断（主管 → 级别 → 地域 → 专属 → 协议）

**【考点定位】** 先主管后管辖，每年必考。

**【踩分步骤】**
1. 主管：是否属法院主管——存在有效仲裁协议→交仲裁；劳动争议→仲裁前置；其他依多元解纷机制排除。
2. 级别管辖：基层为原则；中院管辖：重大涉外、本辖区重大影响、最高院指定（海事、专利、公益诉讼、仲裁相关等）。
3. 地域管辖：一般"原告就被告"；特殊：侵权（侵权行为地/被告住所地）、合同（履行地/住所地）、保险/票据等。
4. 专属管辖：不动产纠纷→不动产所在地；港口作业→港口所在地；继承→被继承人死亡时住所地/主要遗产地。
5. 协议管辖：书面协议选择与争议有实际联系地点的法院，不得违反级别/专属管辖。
6. 管辖权恒定 + 管辖权异议（答辩期内提出，不停止审理）。

**【必写采分点】** "先主管后管辖"、专属管辖三种、协议管辖限制、中院管辖范围。

**【常见失分点】** 跳过主管直接论管辖；不动产纠纷未识别为专属管辖；协议管辖违反专属管辖仍认定有效。

**【一句式示范】** "本案先判断主管——无仲裁协议，属法院主管；系房屋买卖（不动产）纠纷，依专属管辖由不动产所在地法院管辖，当事人协议其他法院无效。"

### 模板 12：当事人适格与第三人

**【考点定位】** 适格当事人 + 有独三/无独三地位。

**【踩分步骤】**
1. 当事人适格：原则为实体法律关系主体；例外（确认之诉、法定管理权人、公益诉讼机关）。
2. 特殊主体：个体工商户（字号/经营者）、挂靠、法人工作人员职务行为、劳务派遣、保证合同（一般保证/连带保证）。
3. 有独立请求权第三人：对诉讼标的有独立请求权，以起诉方式参加，相当于原告，法院不得主动追加。
4. 无独立请求权第三人：与案件处理结果有利害关系，申请或法院追加；判决承担责任的，有权上诉。
5. 必要共同诉讼 vs 普通共同诉讼：诉讼标的同一（必要，合一判决） vs 同种类（普通，可分之诉）。

**【必写采分点】** 有独三"相当于原告、法院不主动追加"；无独三"判责方可上诉"；必要/普通共同诉讼区分。

**【常见失分点】** 混淆有独三与无独三上诉权；漏特殊主体（挂靠、劳务派遣）的适格规则。

**【一句式示范】** "丙对甲乙争议标的具有独立请求权，为有独三，应起诉参加，相当于原告；法院不得依职权追加。若丙仅与结果有利害关系则为无独三，判其担责方可上诉。"

### 模板 13：证明责任分配（一个原则 + 两类倒置）

**【考点定位】** 谁主张积极事实谁举证；侵权/环境倒置。

**【踩分步骤】**
1. 一般规则：主张法律关系存在的当事人，对产生该关系的基本事实举证；主张变更/消灭/妨碍的，对该事实举证。
2. 合同纠纷：主张合同成立并生效的，对成立生效举证；主张已履行的，对履行举证；主张违约的，对违约举证。
3. 侵权纠纷：原告就侵权行为、损害结果、因果关系、过错（一般侵权）举证；过错推定/因果关系倒置情形由被告反证（环境污染、高度危险等）。
4. 自认：一方明示承认于己不利事实，对方免证（代理人自认除明确否认外有效）。
5. 免证事实：自然规律、众所周知、生效裁判/仲裁/公证确认等。

**【必写采分点】** "谁主张积极事实谁举证"、侵权一般原告证过错、环境/高危因果倒置。

**【常见失分点】** 把一般侵权的过错也推给被告；漏自认效力；混淆本证/反证。

**【一句式示范】** "一般侵权中，原告对过错举证；本案属环境污染，因果关系倒置由被告证明不存在因果关系，原告仅证污染行为与损害结果。"

### 模板 14：二审裁判方式 / 再审事由

**【考点定位】** 二审维持/改判/发回；再审启动与审理。

**【踩分步骤】**
1. 二审审理范围：围绕上诉请求，但一审违反禁止性规定或损害国家/社会/他人利益除外；全面审查。
2. 二审裁判：
   - 原判事实清楚、适用法律正确 → 驳回上诉、维持；
   - 事实清楚但法律适用错/责任不当 → 改判；
   - 事实不清/证据不足 → 查清改判或发回；
   - 程序严重违法（如遗漏当事人、违法缺席）→ 发回重审。
3. 上诉不加刑：仅有被告人上诉时不得加重。
4. 再审：事由含新证据、基本事实缺证、主要证据伪造/未质证、法律适用错、审判组织不合法、剥夺辩论权等；启动：法院依职权、当事人申请、检察院抗诉/检察建议；原一审按一审、原二审或提审按二审。

**【必写采分点】** 二审三种结果、程序违法发回、上诉不加刑前提、再审13事由（列要点）。

**【常见失分点】** 漏"上诉不加刑仅被告人上诉"；再审事由记不全；混淆二审与再审审理程序。

**【一句式示范】** "一审遗漏必要共同诉讼人，属严重程序违法，二审应撤销原判、发回重审；本案被告人上诉、检方未抗，须适用上诉不加刑。"

## 五、行政法（李佳 · 合法性审查）

### 模板 15：行政行为合法性审查五要件（万能模板）

**【考点定位】** 主体 → 证据 → 法律依据 → 程序 → 裁量。

**【踩分步骤】**
1. 主体合法：作出机关是否有法定职权（越权/无权限即违法）。
2. 事实清楚、证据确凿：事实认定是否清楚、证据是否充分。
3. 适用法律、法规正确：依据是否准确（含上位法优于下位法）。
4. 符合法定程序：是否履行告知、听证、说明理由、期限、送达等程序义务。
5. 无滥用职权、无明显不当：裁量是否显失公正、违反比例原则。
6. 结论：合法 → 驳回原告诉讼请求；违法 → 撤销/确认违法/履行判决。

**【必写采分点】** 五要件逐条过、结论对应判决类型、比例原则（明显不当时）。

**【常见失分点】** 五要件只写两三条；漏程序要件；结论不接判决类型。

**【一句式示范】** "该处罚主体合法、事实清楚，但作出前未告知陈述申辩权，违反法定程序，依五要件审查属违法，法院应判决撤销（或确认违法）。"

---

### 模板 16：被告确认（最高频）

**【考点定位】** "行政主体 = 行政诉讼被告"核心等式。

**【踩分步骤】**
1. 作出行政行为的行政机关 → 该机关为被告。
2. 法律、法规、规章授权组织 → 该组织（有被告资格）。
3. 受委托组织 → 委托的行政机关为被告。
4. 经批准的行政行为 → 对外署名的"名义机关"为被告。
5. 内设/派出机构：有法律授权以自己名义→自己；无授权→所属机关（种类越权时为其所属机关）。
6. 共同行为 → 共同被告；假共同行为中行政主体为被告、非行政主体为第三人。

**【必写采分点】** 授权组织有资格、委托机关为被告、名义机关原则、共同被告。

**【常见失分点】** 把受委托组织当被告；漏"经批准的以名义机关为被告"；派出机构种类越权归所属机关。

**【一句式示范】** "该行为由派出所（派出机构）以自己名义作出拘留，拘留属种类越权，被告应为其所属公安局，而非派出所自身。"

### 模板 17：受案范围判断

**【考点定位】** 具体行政行为 + 行政协议 + 部分抽象行为附带审查。

**【踩分步骤】**
1. 定性：被诉行为是具体行政行为（特定性、处分性、外部性、单方性）/ 行政协议 / 可附带审查的规章以下规范性文件。
2. 可诉性判断：属于受案范围——行政处罚、强制、许可、确权、征收、不履行法定职责等。
3. 排除：内部行为、国家行为、刑事司法行为、抽象行政行为（原则）、调解仲裁等。
4. 结论：属于/不属于受案范围；不属于则裁定不予受理或驳回起诉。

**【必写采分点】** "具体行政行为四要素"、可诉类型列举、排除情形、不属于则裁定驳回。

**【常见失分点】** 漏具体行政行为四要素；把内部行为/刑事司法行为误判可诉。

**【一句式示范】** "该行为针对特定对象、产生实际权利义务影响、对外发生效力、单方作出，属具体行政行为，具有可诉性，属于受案范围。"

### 模板 18：一审判决类型选择

**【考点定位】** 合法→驳回；违法作为→撤销/确认；违法不作为→履行/确认。

**【踩分步骤】**
1. 被诉行为合法 → 驳回原告诉讼请求。
2. 作为违法：
   - 可撤销（超越职权、主要证据不足、适用法律错误、违反程序、滥用职权/明显不当）→ 撤销判决；
   - 不可撤销（给国家/公共利益重大损害、无撤销内容、程序轻微违法不影响权利）→ 确认违法判决。
3. 不作为违法：
   - 履行仍有意义 → 履行判决；
   - 履行无意义 → 确认违法判决。
4. 注意：行政诉讼无"维持判决/确认合法判决"（法院是外部中立第三方）。

**【必写采分点】** 合法驳回、撤销五情形、确认违法三种不可撤销、无维持判决。

**【常见失分点】** 写出"维持判决"（行政法禁）；混淆可撤销与确认违法边界；漏履行判决。

**【一句式示范】** "被诉处罚主要证据不足，属可撤销情形，法院应判决撤销；若撤销会给国家利益造成重大损害，则判决确认违法但不撤销。"

### 模板 19：国家赔偿归责原则

**【考点定位】** 违法归责 / 过错归责 / 结果归责三元体系。

**【踩分步骤】**
1. 一般行政行为：违法归责——行为违法即赔；未违法但有合理注意且无法避免→不赔（可行政补偿）。
2. 刑事司法中的逮捕、判决：结果归责——只要发生损害结果（如无罪羁押、无罪判决），不论是否违法/过错，国家均赔。
3. 刑事司法事实行为：过错归责——以理性第三人合理注意义务为标准。
4. 构成要件：侵权职务行为 + 损害事实 + 因果关系。
5. 赔偿方式：赔偿金、返还财产、恢复原状；标准按人身/生命/财产分别计算。

**【必写采分点】** 三元归责体系、结果归责适用于无罪羁押、违法归责适用于一般行政。

**【常见失分点】** 把结果归责误用到一般行政；漏构成要件三要素；混淆行政赔偿与补偿。

**【一句式示范】** "甲被逮捕后经审判无罪，依结果归责原则，不论逮捕是否违法，国家均应承担赔偿责任；若系一般行政处罚违法致损，则适用违法归责。"

### 模板 20：行政法主观题通用答题范式（五步法 + 六类题型微模板）

**【考点定位】** 所有行政法主观题（含选做题、真题）的通用输出引擎。母本：2024 万兴公司案 6 问官方参考答案（行为性质 / 程序时间点 / 被告确定 / 行政执行 / 复议程序 / 裁量基准）。本模板专治"考点会辨、输出弱"——把要点罗列升级为法言法语分析。完整真题拆解见 `法考主观题_行政法标准答题模板_万兴公司真题拆解.md`。

**【踩分步骤】** —— 五步法（每问必走，真题答案从不"列要点"）

1. **结论先行**：定性 / 判断 / 处理方式一句话占首句（占分最高），如"属于行政强制措施""不予准许""共同被告"。
2. **法条锚定**：必引《XX法》第X条，条号即采分点（开卷可查，但答案须写条号）。无条号 = 无"有法可依"证明 = 丢分。
3. **要件展开**：把法条拆成可采分的小点，用 ①②③ 分层。如强制措施定义拆"限制人身自由 0.5 + 控制财物 0.5"。
4. **归入本案**：将要件逐一对应题干事实（"本案中……符合……"）。
5. **闭合**：排除干扰项（"故不属于行政处罚"）或落到判决 / 处理结论。每个定性必落后果。

**六类题型微模板**（先判断题型 → 套对应结构）：

- **A 行为性质定性**（强制措施 vs 处罚）：结论 + 概念（引定义拆要件） + 本案归入 + 反排。示范："属于行政强制措施（《行政强制法》第2条：为制止违法、防止证据损毁、避免危害发生、控制危险扩大，对人身暂时性限制或对财物暂时性控制的行为）。本案基于重大隐患、具临时性紧急性、为预防危险而非最终处理，故属强制措施，不属于行政处罚。"
- **B 程序法时间点判断**（增加诉讼请求截止 / 起诉期限）：结论 + 法条（引程序法条及时间点） + 本案归入（何时提出→超期否） + 闭合。示范："不予准许。依《行诉解释》第70条，起诉状副本送达被告后原告提新请求不予准许（正当理由除外）。本案庭审中增加请求，超截止时间，故不准许。"
- **C 被告 / 管辖确定**（复议维持共同被告）：先定复议机关（复议法§24 工作部门→本级政府） + 再定被告（行诉法§26 复议维持→原机关 + 复议机关共同被告） + 结论。注意 2024 新复议法"工作部门→本级政府"是高频坑。
- **D 行政处理 / 执行措施**（逾期罚款等）：结论 + 法条分项（处罚法§72 每日 3% 加处罚款且不过原额；无直接强制权→申请法院执行）。铁律：行政机关大多无直接强制执行权，"加处罚款 + 申请法院"二元。
- **E 复议 / 诉讼程序规则**（听取意见 / 听证）：结论（应 / 可以 XX） + 法条分项（复议法§49/50 普通程序应听取意见并记录；重大疑难应听证；认为必要或申请人请求可听证） + 例外（不能听取可书面）。
- **F 抽象行为 / 裁量基准规则**（制定原则）：结论（可制定 + 应公布） + 法条（处罚法§34 可制定裁量基准规范裁量权，应向社会公布） + 要件。

**【必写采分点】** 五步法缺一不可；法条条号必写；每个定性 / 违法点必落后果（撤销 / 确认违法 / 不予准许 / 驳回）；术语法言法语（"暂时性控制""直接损失""起诉状副本送达被告后"）。

**【常见失分点】** 只列要点不引条号；列完违法点不落判决（如把已解除行为错判"撤销"）；术语口语化（"实际损失"应为"直接损失"）；结论不占首句。

**【一句式示范】** "该查封属行政强制措施（§2），但程序违法（仅一人执法违反§18②、未出示证件违反§18③、清单一人签未列明细违反§18⑧及§24）；已解除无撤销内容，故应确认违法（§74②①）；赔偿仅直接损失（§国家赔偿法36），间接损失不赔。"
