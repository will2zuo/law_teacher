### 考点1 公司（法人）人格否认制度——公司股东滥权 ★
**要点**：主体：存在权利滥用的恶意股东 + 行为：滥用法人独立地位和股东有限责任（财产/人格混同、过度支配控制、资本显著不足） + 结果：严重损害公司债权人利益（无损害则无救济） + 效果：对公司债务承担连带责任

### 考点2 法定代表人和公司对外担保
**类型/情形**：金融机构开立保函或担保公司提供担保 / 公司为全资子公司经营活动提供担保 / 担保合同经单独或共同持有2/3以上对担保事项有表决权股东签字同意

### 考点3 职务代理、无权代理和表见代理——公司员工行为的准确判定
**要点**：职权范围内：以法人/非法人组织名义实施，后果归法人 + 超越职权范围：可能构成无权代理/表见代理 + 判断标准：工作人员职权范围 + 交易习惯 + 效力待定，被代理人可追认 + 相对人催告权、善意相对人撤销权 + 未被追认：行为人承担责任 + 构成：无权代理 + 权利外观 + 相对人善意无过失 + 与被代理人有关联 + 效果：代理行为有效，被代理人承担责任后可向无权代理人追偿 + 看身份：法定代表人 / 工作人员 / 普通员工 + 看权限：职务范围内/超越职权 + 看外观：是否有使相对人合理信赖的授权表象 + 看相对人：是否善意且无过失

### 考点4 异常人章关系——公司能否免责
**类型/情形**：真人假章：有权人签字+假章 → 对公司有效 / 有人无章：有权人签字未盖章 → 通常有效 / 有章无人：仅盖章无有权人签字 → 看相对人是否善意 / 章人分离：印章被盗/伪造 → 公司无过错不担责

### 考点5 行政行为与合同效力
**要点**：合同效力与行政审批、行政许可、行政登记原则上相互独立 + 未经批准：合同未生效，而非无效 + 违反强制性规定：须为‘效力性’强制规定才导致无效

### 考点6 名实不符与合同效力
**要点**：探究当事人真实意思，尊重意思自治 + 通谋虚伪表示：表面行为无效，隐藏行为按法律规定处理 + 名实不符不一定导致合同无效

### 考点7 违法行为与合同效力
**要点**：违反法律、行政法规的效力性强制规定：无效 + 违背公序良俗：无效 + 管理性强制规定不当然导致无效

### 考点8 应当、必须、不得与合同效力
**步骤**：识别规范性质：法律/行政法规层级 → 判断强制类型：效力性 vs 管理性 → 综合认定合同效力

### 考点9 无权处分行为与合同效力
**要点**：无权处分合同本身有效 + 物权变动效力待定，经追认或善意取得可补正 + 区分负担行为与处分行为 + 受让人善意、合理价格、完成公示

### 考点10 恶意代表、恶意代理行为与合同效力
**要点**：恶意代表/代理：代表人/代理人与相对人恶意串通，损害被代理人利益 + 效果：民事法律行为无效 + 举证责任：主张恶意串通一方举证

### 考点11 犯罪行为与合同效力
**要点**：合同效力与犯罪行为原则上分别评价 + 犯罪行为本身导致合同目的违法或违背公序良俗 → 合同无效 + 仅一方构成犯罪，不当然导致合同无效

### 考点12 不动产抵押权预告登记
**要点**：未经预告登记权利人同意，处分该不动产不发生物权效力 + 债权消灭或自能够进行不动产登记之日起90日内未申请登记的，预告登记失效 + 建筑物已办理所有权首次登记且预告登记未失效 → 抵押权自预告登记之日起设立 + 预告登记的财产和办理建筑物所有权登记时的财产一致 + 尚未办理首次登记 → 不享有优先受偿权，但不影响抵押合同效力

### 考点13 担保中的‘物债二分’思维
**要点**：担保合同有效 ≠ 担保物权设立 + 未办理登记/交付：债权人只享合同债权，不享优先受偿权 + 物债二分：负担行为与处分行为分离

### 考点14 法人的担保资格
**要点**：营利法人：原则上具有担保资格 + 非营利法人：以公益为目的的不得为保证人，可为自身债务设担保 + 机关法人：原则上不得为保证人（经国务院批准为使用外国政府/国际经济组织贷款进行转贷的除外）

### 考点15 担保合同无效后的法律后果
**要点**：主合同有效而担保合同无效：按过错分担 + 债权人无过错：担保人与债务人对债权人的经济损失承担连带赔偿责任 + 债权人、担保人有过错：担保人承担不超过债务人不能清偿部分的二分之一

### 考点16 担保的从属性
**要点**：成立上的从属性：主债权不存在，担保不成立 + 效力上的从属性：主合同无效，担保合同无效（独立担保约定原则上无效） + 范围上的从属性：担保责任≤主债务范围 + 移转上的从属性：债权转让，担保权原则上随之转让 + 消灭上的从属性：主债务消灭，担保责任消灭

### 考点17 担保物权的不可分性
**要点**：担保物分割或部分灭失：仍担保全部债权 + 债权分割或部分转让：各债权人可就全部担保物主张权利 + 主债权部分清偿：担保物仍担保剩余债权

### 考点18 担保物权的物上代位性
**要点**：担保期间担保财产毁损、灭失或被征收，担保物权人可就保险金、赔偿金、补偿金优先受偿 + 被担保债权未届清偿期：可提存该代位物

### 考点19 抵押财产
**要点**：建筑物和其他土地附着物 + 建设用地使用权 + 海域使用权 + 生产设备、原材料、半成品、产品 + 正在建造的建筑物、船舶、航空器 + 交通运输工具 + 法律、行政法规未禁止抵押的其他财产 + 土地所有权 + 宅基地、自留地、自留山等集体土地使用权（法律规定除外） + 学校、幼儿园、医疗机构等为公益目的成立的非营利法人的教育、医疗设施 + 所有权、使用权不明或有争议的财产 + 依法被查封、扣押、监管的财产

### 考点20 动产抵押权
**要点**：抵押合同生效时设立（登记对抗） + 未登记不得对抗善意第三人

### 考点21 动产浮动抵押权 ★
**要点**：抵押财产：现有的及将有的生产设备、原材料、半成品、产品 + 主体：企业、个体工商户、农业生产经营者 + 设立：抵押合同生效时设立，登记对抗 + 结晶：债务履行期届满债权未实现等情形发生时，抵押财产确定

### 考点22 超级动产抵押权（购买价金担保权） ★
**要点**：为担保价款债权而设立 + 标的物交付后10日内办理抵押登记

### 考点23 抵押财产的转让
**要点**：抵押期间，抵押人可以转让抵押财产（当事人另有约定除外） + 抵押财产转让的，抵押权不受影响（抵押权追及效力） + 抵押人应及时通知抵押权人

### 考点24 借新还旧
**要点**：旧贷担保人原则上不对新贷承担担保责任（同意继续担保除外） + 新贷与旧贷担保人相同：可推定其知道借新还旧

### 考点25 质押权
**要点**：设立：出质人交付质押财产时设立 + 权利凭证：仓单、提单等 + 可质押权利：汇票、本票、支票、债券、存款单、仓单、提单、基金份额、股权、知识产权中的财产权、应收账款等 + 设立：有权利凭证的交付；无权利凭证的登记

### 考点26 留置权
**要点**：合法占有债务人的动产 + 债权已届清偿期 + 动产之占有与债权属同一法律关系（企业之间留置除外）

### 考点27 保证和债务加入的识别
**要点**：保证：从属性、补充性、或然性 + 债务加入（并存的债务承担）：第三人加入债务，与原债务人并列承担 + 约定不明：推定为保证

### 考点28 保证方式 ★
**要点**：保证人享有先诉抗辩权 + 债权人须先就债务人财产强制执行无效果后，方可请求保证人 + 债权人可任意选择债务人或保证人主张责任

### 考点29 保证期间 ★
**要点**：有约从约，不得早于主债务履行期限 + 无约：主债务履行期届满之日起6个月 + 一般保证：债权人未在保证期间对债务人起诉/仲裁，保证人免责 + 连带保证：债权人未在保证期间请求保证人，保证人免责

### 考点30 保证责任 ★
**要点**：主债权及利息、违约金、损害赔偿金、实现债权费用 + 有约从约，不得超出主债务范围 + 债权转让未通知保证人，对保证人不发生效力 + 主合同变更加重债务：未经保证人书面同意，对加重部分不担责

### 考点31 保证人（担保人）的法定代位权
**要点**：保证人承担保证责任后，有权在其承担范围内向债务人追偿 + 享有债权人对债务人的权利（代位权），不得损害债权人利益

### 考点32 定金
**要点**：书面形式约定 + 实际交付定金时成立 + 数额不得超过主合同标的额的20% + 给付方违约：无权请求返还定金 + 收受方违约：双倍返还定金 + 违约金与定金不得并用

### 考点33 共同担保
**要点**：各担保人按约定份额承担责任 + 承担责任后向债务人追偿，不得向其他担保人追偿 + 债权人可向任一担保人主张全部债权 + 担保人承担责任后可向债务人追偿 + 向其他担保人追偿：按内部份额分担

### 考点34 反担保
**要点**：为担保人追偿权的实现而设立 + 反担保人可以是债务人或第三人 + 反担保方式：抵押、质押、保证等

### 考点35 担保案件的争议解决方式与管辖法院
**要点**：债权人一并起诉债务人和担保人：按主合同确定管辖 + 仅起诉担保人：按担保合同确定管辖 + 主合同/担保合同有协议管辖：从约定

### 考点36 合同保全——债权人代位权诉讼 ★
**要点**：债权人对债务人享有合法到期债权 + 债务人对相对人享有合法到期债权 + 债务人怠于行使权利（不以诉讼/仲裁方式主张） + 影响债权人债权实现

### 考点37 合同保全——债权人撤销权诉讼 ★
**要点**：债权人对债务人有合法有效债权 + 债务人实施诈害行为 + 影响债权人债权实现 + 有偿行为需相对人恶意

### 考点38 动产所有权保留买卖合同
**要点**：出卖人对标的物保留所有权以担保价款债权 + 未经登记不得对抗善意第三人 + 取回权：买受人未按约定支付价款等情形

### 考点39 让与担保合同 ★
**要点**：名为转让所有权，实为担保债权 + 按担保关系处理，不确认所有权归债权人 + 完成财产权利变动公示的，可参照担保物权优先受偿 + 流押/流质条款无效

### 考点40 动产融资租赁合同
**要点**：出租人享有租赁物所有权，承租人享有使用权 + 融资租赁具有担保功能，可登记对抗善意第三人 + 租金加速到期：承租人未支付租金达一定条件

### 考点41 有追索权的保理合同
**要点**：保理人可向应收账款债权人主张返还保理融资款本息或回购应收账款 + 也可向应收账款债务人主张应收账款债权 + 保理人向债务人主张后，仍有权向债权人追索

### 考点42 缔约过失责任
**要点**：发生在合同订立过程中 + 一方违反诚信原则（假借订立合同恶意磋商、隐瞒重要事实、泄露商业秘密等） + 对方遭受信赖利益损失 + 因果关系

### 考点43 预约合同和本约合同
**要点**：当事人约定在将来一定期限内订立合同的认购书、订购书、预订书等 + 一方不履行预约义务，对方可请求其承担预约违约责任或解除预约并赔偿损失 + 不得强制订立本约 + 预约所指向的正式合同 + 具备本约主要条款且一方已履行主要义务并被接受的，可认定为本约成立

### 考点44 第三人代为履行（清偿）
**要点**：债务人不履行债务 + 第三人对履行该债务具有合法利益 + 债务性质/约定/法律未排除第三人代为履行

### 考点45 双务合同履行抗辩权
**要点**：先履行方有确切证据证明对方有丧失履行能力情形 + 可中止履行并及时通知对方

### 考点46 司法终止合同——情势变更和合同僵局 ★
**要点**：合同成立后，合同基础条件发生重大变化，不可归责于当事人 + 继续履行显失公平 + 可重新协商；协商不成可请求法院/仲裁机构变更或解除合同 + 非金钱债务履行不能或履行费用过高等 + 致使不能实现合同目的 + 违约方可请求法院/仲裁终止合同权利义务关系

### 考点47 债权转让（让与）
**要点**：存在有效债权 + 债权具有可让与性 + 让与人与受让人达成合意 + 通知债务人（未通知对债务人不发生效力） + 受让人取得债权及从权利 + 债务人对让与人的抗辩可向受让人主张 + 债务人可向受让人主张抵销

### 考点48 债务加入（并存的债务承担）
**要点**：第三人加入债务，与原债务人并列承担 + 债权人可请求任一债务人履行 + 第三人的加入不影响原债务人地位

### 考点49 以物抵债协议（代物清偿协议）——协议签订时间是核心 ★
**要点**：约定债务人到期没有清偿债务以物抵债：参照担保制度处理 + 禁止流押/流质 + 当事人意思表示真实，协议有效 + 未履行的，债权人可请求履行原债务或以物抵债协议 + 完成公示的，可请求对抵债财产优先受偿

### 考点50 清偿抵充 ★
**要点**：约定抵充优先 + 指定抵充：债务人指定 + 法定抵充：已到期债务→缺乏担保/担保最少→负担较重→到期在先→按比例 + 实现债权费用 → 利息 → 主债务

### 考点51 合同解除权 ★
**要点**：不可抗力致不能实现目的 + 预期违约 + 迟延履行经催告仍不履行 + 根本违约致不能实现合同目的 + 通知到达对方时解除 + 对方有异议可请求法院/仲裁确认 + 直接以提起诉讼/仲裁方式主张解除

### 考点52 合同（债）抵销权
**要点**：双方互负债务、标的物种类品质相同、均到期 + 通知到达对方时生效 + 根据债务性质不得抵销 + 按约定不得抵销 + 因故意侵权产生的债务

### 考点53 民事责任 ★
**类型/情形**：违约责任、侵权责任、缔约过失责任 / 按份责任、连带责任、补充责任

### 考点54 损害赔偿金 ★
**要点**：实际损失 + 可得利益损失 + 不得超过违约方订立合同时预见/应当预见的损失 + 违约金低于损失：可请求增加 + 违约金过分高于损失：可请求适当减少

### 考点55 违约金 ★
**要点**：以实际损失为基础 + 兼顾合同履行情况、当事人过错程度、预期利益等 + 一般超过损失30%可认定为‘过分高于’

### 考点56 买卖合同中的风险负担
**要点**：交付前风险由出卖人承担，交付后由买受人承担 + 买受人违约未受领：违反约定时起风险转移 + 在途标的物：合同成立时风险转移 + 交付地点不明：货交第一承运人后风险转移

### 考点57 房屋承租人的优先购买权
**要点**：出租人出卖租赁房屋应提前15日通知承租人 + 承租人享有以同等条件优先购买的权利 + 房屋按份共有人行使优先购买权或出租人卖给近亲属的除外 + 出租人未通知：承租人可请求赔偿，但不得主张买卖合同无效

### 考点58 建设工程施工合同 ★
**要点**：承包人未取得资质或超越资质：合同无效 + 必须招标未招标/中标无效：合同无效 + 建设工程经验收合格：可参照合同约定折价补偿 + 承包人享有的优先受偿权 + 优先于抵押权和其他债权 + 行使期限：自发包人应当给付工程款之日起18个月

### 考点59 夫妻共同债务的认定和清偿 ★
**要点**：共同签名或事后追认的债务 + 一方为家庭日常生活需要所负债务 + 一方超出日常生活需要：债权人证明用于夫妻共同生活、共同生产经营或基于共同意思表示 + 共同债务：夫妻共同清偿 + 离婚时：共同财产不足清偿或财产归各自所有的，由双方协议；协议不成由法院判决

### 考点60 夫妻共有股权的处分和分割
**要点**：婚后以夫妻共同财产出资取得的股权：股权本身为个人财产，但股权收益/增值为共同财产 + 实践中存在争议，需结合出资来源、登记等判断 + 夫妻一方转让股权：参照公司法股权转让规则 + 离婚分割股权：协商处理；协商不成可评估后作价补偿或依法分割

### 考点61 单位用工责任
**要点**：工作人员因执行工作任务造成他人损害，由用人单位承担侵权责任 + 用人单位承担责任后可向有故意或重大过失的工作人员追偿 + 被派遣工作人员因执行工作任务造成他人损害，由接受派遣的用工单位承担 + 劳务派遣单位有过错的，承担相应责任 + 提供劳务一方因劳务造成他人损害，由接受劳务一方承担 + 提供劳务一方因劳务自己受损害：按双方过错承担
